# GitHub公开副本说明

本次同步 alpha_lab 的代码、配置、研究文档、目录索引，以及当前模型权重和可审阅的轻量报告。最新行情/模型记录截至2026-10-22；目录整理入口为 [INDEX.md](INDEX.md)。

大型行情、冻结市场快照、Parquet明细、批量试验子目录、缓存、日志、压缩包与排版工作文件保留在原研究机器。当前仓库不是完整的数据备份；克隆后不能直接复现依赖这些输入的完整扫描。datahub代码沿用仓库已有版本，本次没有同步其最新私有数据或源码变更。

原始运行manifest用于保存本地来源和哈希线索；部分文件未上传，部分源码因去除凭据而变化，因此不能将原manifest视为此公开包的完整性核验。公开副本的实际文件哈希及脱敏记录见 PUBLICATION_MANIFEST.json。重新部署需准备合法数据访问权限、对应数据快照并重新生成/核验产物。

数据接口令牌通过 TUSHARE_TOKEN 环境变量或本机凭据文件提供。个人通知收件地址已替换为示例地址。GitHub认证令牌未存入任何文件或提交。

Python代码保留研究环境中的路径约定；在其他机器运行前需按配置准备路径和外部依赖。当前策略继续暂停年度板块过滤，历史报告不代表现行收益承诺。

GitHub直接阅读 INDEX.md；下载后可在浏览器打开 INDEX.html 使用搜索。网页索引按本次公开文件重新生成，容量统计仅代表公开副本。

配套程序至少包含 datahub/scripts/update_data.py、build_dataset.py、frozen_research.py 及 datahub/src/datahub/frozen.py；本机对应哈希见 EXTERNAL_DEPENDENCIES.json。索引测试3项在公开副本独立通过；年度板块暂停规则测试7项在提供本机完整datahub依赖后通过，未宣称公开副本可以独立运行全流程。
