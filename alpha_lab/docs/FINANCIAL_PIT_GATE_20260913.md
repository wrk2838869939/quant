# 经营与现金流增量研究：历史版本准入检验

日期：2026-09-13。**本轮确认一个具体的数据时点缺陷：同一行财务指标可能混合初报与后来更正值，整行共用的`ann_date`不能保证全部字段当时可见。** 财务增强模型尚未训练，不能报告收益改善或认定财务特征无效。2024+行情及生产均未改动。

研究继续沿用最多五股、月度复核与长期持有方向。本轮先固定两项候选：单季度营收同比增速较上年同期的变化，以及单季度经营现金流/营收比较上年同期的变化。没有依据后续收益改选特征、删除股票或调整阈值。

完整原始文件、复现脚本和独立核验见[本轮目录](../outputs/financial_pit_audit/20260913T070937_341943Z/)。

## 1. 已确认的混合版本实例

康美药业2018年度报告在2019-04-30披露经营现金流净额为−3,191,529,576.31元。2020-06-18披露的下一年年报将该数重述为+305,616,727.44元。两份原PDF均已逐页核查及归档：[2018原年报](https://static.cninfo.com.cn/finalpage/2019-04-30/1206168292.PDF)、[2019年报中的重述](https://static.cninfo.com.cn/finalpage/2020-06-18/1207936073.PDF)。

| 项目 | 原公告口径 | 后来更正口径 | 现有指标缓存 |
|---|---:|---:|---:|
| 2018经营现金流净额 | −31.9153亿元 | +3.0562亿元 | 未存总额 |
| 用年末股本计算的每股经营现金流 | 约−0.6417元 | 约+0.0614元 | `ocfps=+0.0614` |
| 2018基本每股收益 | 0.184元 | 0.0302元 | `eps=0.184` |
| 指标行公告日期 | 2019-04-30 | 更正实际披露于2020-06-18 | 仍为2019-04-30 |

同一行EPS保留初报、现金流每股数匹配后来更正，不能简单把整行都叫“最新值”或“原始值”。把这行在2019年送入模型，会让该现金流字段提前出现。**本轮尚未量化全表受影响比例，也没有证明它影响了此前只用价量的P2/P3结果。**

反向证据同样保留：宁波港2018/2019、大秦铁路2019共有13项数值或公式与原公告一致；宁波港2018扣非仍保留原值，而非下一年重述值。康美2018Q3的两项拟选季度指标也可由原公告复算。局部正确与局部混版本同时存在，因此按字段与版本取证，不能整表判真或判假。

## 2. 已尝试替代数据源，尚不能恢复完整初报

对固定康美2018年度分别请求利润表、现金流量表的类型1、4、5，共六次，最多两并发。当前代理返回的现金流类型1明确记录：

```text
ann_date=20190430
f_ann_date=20200618
update_flag=1
n_cashflow_act=305616727.44
```

这是原指标表缺失的实际公告时间证据。四个类型4/5请求均为空；空响应不足以证明所有公司均无旧版本，也不能证明该过滤功能在全接口上有效，但**本次接口路径没有取回这个案例的调整前原值**。

官方文档区分公告日、实际公告日和调整前/调整后报表，类型1是最新合并表；`update_flag`也不能单独替代一条完整的发布时间历史。[现金流接口说明](https://tushare.pro/document/2?doc_id=44)、[指标接口说明](https://tushare.pro/document/2?doc_id=79)。原始响应见[版本探针](../outputs/financial_pit_audit/20260913T070937_341943Z/version_api_probe/)。

## 3. 覆盖不差，版本问题不能用覆盖率掩盖

只读取公告日及期末均不晚于2023年底的190,204条财务记录。原243,955个机会全部保留，其中76,213个符合原趋势条件；未读取收益标签。

两个变动值同时为有限数的趋势机会覆盖率：

| 年份 | 数值覆盖率 |
|---|---:|
| 2018 | 92.71% |
| 2019 | 98.82% |
| 2020 | 98.94% |
| 2021 | 98.24% |
| 2022 | 99.05% |
| 2023 | 99.29% |

这只是“有数值”，不代表“当时可用”。没有根据财务缺失排除股票，也没有把同覆盖子集的表现当作新alpha。第一次警报的原五股均有两项数值；其最新报告期均为2021-09-30，距离2022-01-25已有117日。这提示季度财务是慢信息，是否能帮助判断一次回调仍需检验，不能仅凭有数据就把它当成即时风险信号。

## 4. 已实现并验证的连接规则

- 公告日严格早于复核日；同日公告不使用，避免未知发布时间进入当日决策。
- 按已公布的最新报告期取值；晚到旧期修订更新旧期比较数，不顶替新报告。
- 上年同期也只使用当时可见版本；最新报告缺值时不偷偷回填旧值。
- 28条非标准期末记录保留为合法报告；若成为最新报告，不计算季度变动，不删除股票。
- 输出当前/同期报告的公告日、期末、年龄、数值可得标记；未经源版本认证，阻止进入历史增量模型。

新增8项测试覆盖同日公告、晚修订、冲突、非标准期末、未知资料及未来记录不影响过去。**完整252项测试通过。** 真实机会另完成2021-12-01的2805行未来事件截短与源顺序不变检查；独立实现再核对全243,955行的来源日期与四个数值，误差为0；228个固定分层样本＋314个真实边缘样本，以及原五持仓直接过滤原表复核通过。边缘样本包括176个最新期缺值和138个晚到旧期公告；当前期多可见版本的真实样本为0，该分支由合成测试覆盖。详情见[验证目录](../outputs/financial_pit_audit/20260913T070937_341943Z/coverage_verification/)。

首次连接因过严标准季度检查拒绝28条记录，修复后未删行；探针末尾出现NumPy布尔值JSON序列化错误，六份原响应均已保存，仅从缓存重建清单，没有重复请求。两次失败及修复前源码保留。

## 5. 本轮决定与下一步边界

本轮在**财务源时点准入**处停止训练，没有运行收益回测或新增卖出规则。此前价量对照保持原样；不能据此宣称财务信息无效。

后续应先建立来自原公告的初报及更正事件记录，至少保留公司、报告期、实际可用日、报表版本、原始值、单位与出处。季度现金流和营收应由同版本累计报表推导，并明确后来的比较期修订何时进入计算。单纯给当前缓存整体滞后一天、丢掉康美或只取`update_flag=1`都不能修复已经回填的历史。

有可复现的版本来源后，才启动同覆盖价量对照与两项财务增量比较，再检查最终五股的预测误差、退出后走势及真实整手账户；不扩大特征搜索来绕过这道数据问题。
