## 固定的具体定义

固定的是此前内层选参产生的年度路径，不是一个始终不变的窗口。该路径被完整登记并校验来源ID、内层截止日期及参考文件哈希，入口不再次搜索。

| 基线 | 2021 | 2022 | 2023 |
|---|---|---|---|
| B01 | 26日低换手、周频、3只 | 108日、周频、5只 | 119日、周频、5只 |
| B02 | 19日低波、月频、3只 | 115日低振幅、周频、5只 | 32日低波、月频、3只 |
| B03 | 正EP、排除流通市值最小7%、月频、4只 | 正EP、排除最小29%、周频、5只 | 正EP、排除最小23%、周频、5只 |

B01为负的窗口平均换手率；B02为负的收益标准差，或负的平均(high-low)/pre_close；B03为正PE_TTM的倒数，并按当日可选截面流通市值分位过滤。实际实现仍由受哈希保护的`src/rule_search.py`提供。

三条基线2021年均亏损，B01的收益主要出现在2023年；不能把累计通过验收解释为每年稳定盈利。没有登记2023年之后的年度参数，不会自动延用最后一组参数。

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \

  --release datahub/releases/selection_v1_20260920 \

```

评估候选评分/过滤模块：

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \
python datahub/scripts/frozen_research.py run \
  --release datahub/releases/selection_v1_20260920 \
  alpha_lab/scripts/run_selection_baselines.py \
  --candidate alpha_lab/configs/baseline_identity_candidate.yaml
```

复制候选配置并设置唯一ID、父基线、模块名、函数名和参数；新策略放在`src/`的独立Python模块。函数签名：

```python
def transform_scores(scores, *, context, params):
    # 返回同日期、同股票列的分数；NaN代表不参与排名。
    # 任何日期的输出只可使用该日期及之前的信息。
    return scores
```

context包含历史宽表、资格表、交易日历、当前年度及该年度基线参数。按年度批处理不允许使用年度未来信息；入口会截断真实行情后重新生成信号并比较过去，检测常见全期统计/未来填补。有限截止点核验不是完整因果性证明，新模型训练仍需独立标签成熟检查。

该接口保持父基线的调仓频率、持股数和成交框架，适合先隔离评分与过滤的效果。修改持仓退出、频率、仓位或执行时，应新增独立实验入口及配对协议，不能悄悄改变基线。

每次生成独立运行目录，保存源码/配置哈希、信号、账户、逐笔交易、持仓、事件、年度指标及相对父基线的收益/回撤/费用变化。`delta_mdd_pp`为正表示回撤变浅。候选通过历史验收不会自动覆盖基线。

## 学习组合的后续约束

学习组合应把原样基线作为显式候选，并先验证单一基线权重为1时可重现其选股与账户。已有identity验证只证明候选接口不损坏基线，尚未证明训练器能够找到它。旧学习实验与基线的特征窗口、筛选条件、模型目标并不一致，且IC权重分支没有明确的单因子候选；详见[学习未回到基线的解释](BASELINE_LEARNING_GAP_20260920.md)。

改进选参必须在规定内层比较原样基线、稀疏组合与新增模型，保留已测非单调邻域和成本。已观察的外层历史仅供研发比较，不能再宣称新鲜检验；内层回退基线也不保证未来一定不劣。
