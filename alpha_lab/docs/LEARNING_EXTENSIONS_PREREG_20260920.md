# 第二批学习策略实验约定

本约定在第二批试跑前写入。沿用冻结发布 `selection_v1_20260920`、93只股票执行样本、10万元初始资金、30%最大回撤准入标准及既有成交引擎。第一批四类失败记录保留；不按历史胜者删除特征。

本轮七类：

| 类别 | 实际测试定义 |
|---|---|
| 神经网络 | 单隐层MLP，ReLU/Tanh；固定轮数训练，不以未来样本早停 |
| 状态专家 | 用训练期市场收益、波动、广度估计KMeans状态；状态内Ridge与全局Ridge混合 |
| 动态因子权重 | 已成熟截面IC序列的EWMA或Kalman估计；本次训练后冻结到下一训练日 |
| 学习型交易过滤 | 固定23因子等权宿主前15名；树/森林预测未来收益超过0.4%的概率，门控选股 |
| 多周期联合预测 | 同时拟合5/10/20日标准化收益或截面排名，预设近端/等权/远端组合；等待最长标签成熟 |
| 相关性分组专家 | 仅用拟合日之前股票收益估计相关性层次聚类，簇内Ridge与全局Ridge混合 |
| 市场风险门控 | 预测当日合格股票等权未来收益跌破阈值的概率，控制固定宿主的持股/现金切换 |

状态模型本轮不是HMM；过滤器宿主不是学习模型，不称为两层学习模型的交叉拟合；市场风险标签不是实际账户回撤；多周期Ridge为共享输入的多输出回归，不声称隐层任务共享。CNN、HMM、GP、持仓退出学习及完整元标签堆叠仍留待后续。海外映射与分钟强化学习不在本轮冻结样本范围。

每类每折16组（3折共336组正式策略参数），外加每类4组工程试跑。每折内层从2020年到外层年之前；外层2021/2022/2023年连续账户。重训周期3或6个月，训练窗252/504交易日；日/周/月调仓，3或5只股票。不同类别训练量另行统计，不能用参数组数声称计算预算完全公平。

参数域见 `configs/learning_extensions_v1.yaml`，正式运行前归档代码及配置哈希。先8组联合全局探索，再4组局部一/两轴邻域，再4组全局补充。局部邻域不要求单调；记录全部尝试，包括失败与空仓。可行参数必须有买入且内层连续账户与各年度回撤均不超过30%；无可行候选则该外层年度持现金。模型、特征、标签、参数、逐笔交易、持仓、事件、账户均归档。

门控提供同参数、同频率、同持股数的取消门控对照；这是整体门控效果，不足以排除仓位变化的解释。另提供预设50%研究资本加50%无息现金的独立静态仓位参照（不据外层表现校准仓位）。门控阈值并非30%回撤保证。

严格时序：标签结束日早于拟合日；所有标准化/聚类均只拟合历史；市场上下文按当日可选截面计算，无全样本归一化；信号收盘完成、次日开盘成交。检查真实历史截断后的预测一致性、保存模型重放、账户前缀重放及独立资金/持股台账。

93股样本含全窗口数据质量隔离偏差；2021–2023历史已观察，本轮是继续研究的滚动留出评价，不能恢复成未接触的最终检验。30%仅为该研究窗口的验收线，不是未来损失上限。
