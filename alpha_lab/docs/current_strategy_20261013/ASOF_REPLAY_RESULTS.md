# 按历史决策时点重做：板块通过后的个股筛选

日期：2026-10-13。行情截至2026-10-12。

**此前随机冻结模型回填的历史“确认买点”不能用于模拟当时决策，本轮撤回这一解释。已经重做年度训练、历史内层选参、标签成熟隔离与个股公告可知检查。现有资料仍缺少历史供应商版本，结果应称“按历史信息边界的条件回放”，不能声称完全恢复当年实盘。**

## 1. 如何模拟历史时点

每年开始前训练一次，全年冻结使用该模型。最早回放2019年；2014—2018年用于历史积累，不用之后的数据倒推早期买点。

- 外层训练最多使用此前8年事件，20日目标标签必须在年初前20个交易日的截止日之前完全结束。未成熟、断行情、跨指数连续段的标签不能训练。
- 内层按完整日期拆分较早拟合段和较晚验证段，二者同样隔离标签结束时间。同一天不同板块不能拆到两边。
- 规则数4/8、学习率0.003/0.01及早停轮数只在历史内层验证集决定。三个种子集成；50%保留阈值、填充、缩放、聚类中心只用当时训练数据估计。
- 每个年度保存训练/验证ID、标签截止日、所选参数和权重。评分输出先落盘，然后才做后续股票收益评价。
- 个股在收盘后决策，最早次日开盘观察。须为该日行业成员、有有效报价和交易量、处于上市存续期；历史名称不能是ST/退市，名称公告必须严格早于决策日，未知或冲突拒绝。
- 板块首次确认日起最多观察5个交易日，要求同一事件、窗口与峰值，且当日仍满足确认；不能把后来出现的其他事件接在旧模型分数上。

这次新增公告日期约束没有改变所覆盖样本的名称筛选结果，但关闭了代码层面的前视入口。

## 2. 旧记录的哪些结论改变

2019—2026年共有256个可评分事件，新流程通过105个。此前固定参数时间推进版本通过118个，两版有33个事件选择不同：旧通过新拒绝23个，旧拒绝新通过10个。随机冻结模型的“双模型通过”口径不再作为主研究范围。

具体例子：2026-08-03电子化学品Ⅱ在新回放中得分−0.013413，年初确定的门槛为0.003289，**未通过**。此前将其列为“模型通过、卡在个股”的说法不适用于历史决策模拟。同日通信设备、半导体通过；2026-09-17酒店餐饮未通过。

原个股规则在本轮回放中的最近候选仍出现在2026-07-23：自动化板块的301021、301568，光学光电子板块的300331。这只是按当前规定流程重建的历史候选，不能称作当时已发送的通知，也没有获得完整成交认证。

## 5. 同日对照和跨年稳定性

固定原规则出现候选的相同事件、相同日期，再替换股票篮子，可初步隔离提前入场造成的变化：

- 取消前期放量：17个事件，较原规则的20日均值增加0.59个百分点；中位差为0。
- 趋势＋价格形态：17个事件，均值仅增加0.03个百分点；中位差为0。
- 强度前5：17个事件，均值降低0.41个百分点；中位差为0。
- 低波前5：17个事件，均值增加0.50个百分点；中位差为0。

同日样本仅17个，不能据此确定排序方式优劣。放宽门槛的主要作用是打开原本没有候选的事件，而不是已证明能够改善原有事件中的选股。

去掉2022年后，取消前期放量的相对同日板块均值从+2.38降为+0.78个百分点，趋势＋价格形态从+1.53降为+0.57个百分点。2026年趋势＋价格形态的绝对20日价格观察均值为+8.64%，但相对同日板块合格成员为−2.40个百分点；绝对上涨不能解释为个股筛选有效。

新增事件独立统计见运行目录的 `added_and_year_sensitivity.csv`；同日对照见 `same_event_same_date_vs_original.csv`；全部年度及3/10/20日结果均已保留。

## 6. 研究判断与剩余缺口

1. 原规则太稀疏这一现象在新时序口径下仍成立，但少交易本身不证明规则有错。
2. 取消前期放量、保留趋势与价格条件能显著增加研究候选，尚未证明净交易优势，不能直接替换生产门槛。
3. 只保留趋势或只保留价格形态，相对同日板块的平均差很小；不能把“板块看好”当作任意个股都适合买入的依据。
4. 前5排序也没有获得稳定优势证据。需要后续真正前瞻记录和完整执行验证；本轮不挑选历史赢家。

最重要的边界：行业历史区间只有生效日期，没有当年公告时间/接收时间；当前日线、复权因子及名称历史可能被供应商修订。策略形态、参数候选网格、个股门槛也是现在制定或继承的，历史开发偏差无法被时间切分消除。因此**算法时间边界已检查，但原始时点数据认证仍未完成**。

官方涨跌停资料覆盖不足，且未实现整手现金、持仓重叠、停牌退出、排队成交和公司行动现金账本。本轮不报告账户收益和最大回撤，也不将任何历史候选称为确认可成交。
