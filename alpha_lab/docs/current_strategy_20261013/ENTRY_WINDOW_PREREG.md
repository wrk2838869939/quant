# 五日入场资格研究：运行前固定方案

本轮只改变板块入场资格的时间语义，保持全部个股量价及趋势阈值、五个平台窗口、事件去重和原板块参数。使用2026-10-12冻结数据；当前实盘配置不变。

比较三组：

1. legacy_today：近五日模型通过事件存在，且当日代表窗口仍确认，复原扫描器的板块级连接方式。
2. same_event_today：确认必须来自首次确认对应窗口、事件、指数段和峰值；消除跨事件拼接。
3. persistent_5d：确认日计为第1日，共5个市场交易日；同一窗口事件保持pullback_gate及near_reference，不再每天要求减速、近期破支撑。事件消失、换峰、换段、跌出参照区或结构失效时永久取消本次资格，之后恢复不能复活旧资格。

全部版本使用当时行业成员，历史名称区间排除ST/退市名称（区间缺失拒绝），不以当前在市名单过滤过去。资格缺口、历史成员修订和历史名称发布时间未完全认证仍须披露。当前扫描在线补充的当日成员无法完整历史复原，不作为历史筛选输入。

主计数同时披露无模型结构对照、原随机留出测试且FNN通过子集、年度时间推进FNN对照。随机留出子集不能当作时间样本外业绩；年度FNN固定原有4/8规则、100轮、学习率0.003和三个种子，按各自训练中位数门槛取或，每年只用已成熟且标签结束早于年初前20交易日的旧事件，不重新按本轮回报挑参。少于60个训练事件的年份不评分，明确作为热身期。超参数继承自已观察历史，时间推进仍不是全新独立测试。

机会单位：事件—股票去重、至少有一只合格股票的板块事件、不同信号日期。另保存全部股票日，避免把多日重复候选当成独立机会。比较新增、消失和提前入场，不能只比较两个总数。

若有新增机会，先做下一交易日复权开盘至3/10/20个交易日后复权开盘观察，未来报价缺失不前向填充，缺口/退市风险单独列示。固定双边费用和滑点仅为成本压力测试，没有涨跌停、整手、现金与公司行动账本认证时，不称实际交易收益或账户回撤，不据此部署。进一步执行验证按新增候选所需元数据覆盖决定；缺数据不能假定成交成功。

成功须有可解释的独立机会增加，且新增机会通过独立的成交与账户风险验证。机会增加很小、或缺少收益证据时保留研究结果，不强行调整生产。
