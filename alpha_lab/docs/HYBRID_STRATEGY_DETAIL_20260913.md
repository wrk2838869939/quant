## 1. 当前策略的准确定位

Hybrid = 主板长期趋势过滤 + 60日平均换手率排序 + 按长期状态调整退出确认 + 现金约束下的整手分配。它是低换手研究主候选，尚未实盘准入。名称中的“混合”指提前退出与耐心确认两种动作，不是多个机器学习模型集成。

配置最多5只、允许现金、月度复核；实际近期651日中650日持5只，唯一零持仓日是初始化。平均仓位98.29%，尚未实现主动空仓。全段2022起也是1134/1135日持5只。

## 2. 股票如何进入候选

每月第一个交易日收盘，使用当时及以前数据：

1. 在有效历史价量数据的合格A股截面计算特征与排名，再限定沪深主板；检查上市天数、ST、退市等条件。
2. 新买股票同时满足60日收益>0、120日收益>0、收盘价>120日均线；趋势使用复权价格。
3. 优先选择过去60日平均换手率较低的股票，保留前20名作为新增持仓候选。同分按股票代码确定次序。
4. 已有持仓不因排名下降被其他股票替换；只有空出的名额才考虑新股，原持仓也不因排名加仓。

当前收益模块给所有股票相同的60日期望收益约3.109%、预期不利变动约13.399%，并非逐股预测。本轮没有改进这两项常数或选股排序。统一正期望与整手利润优化，也解释了账户为何倾向用满仓位。

## 3. 退出规则

原三项趋势条件任一失效，视为当前转弱。只在月度复核判断：

| 转弱时的长期状态 | 退出确认 |
|---|---|
| 120日收益>0且价格>MA120 | 连续第三次月度转弱才退出 |
| 120日收益≤0且价格≤MA120 | 原连续两次兜底；过去20个交易日全部可观察且至少10日弱，可在首次月度转弱时退出 |
| 两个长期条件一好一坏 | 连续两次月度转弱退出 |
| 当前三项趋势均好 | 重置失败计数，继续持有 |
| 当前数据未知 | 不凭未知退出，并打断原失败计数 |

20日内10日是累计，不要求连续；包括复核日。分类切换不清零连续弱计数，连续弱最多到第三次确认。若第二次转弱时从长期两项好变为混合，则当次按两次规则退出。

下一交易日尝试成交；受限无法卖出则保留订单继续重试，之后价格恢复也不能撤销已确认退出。重新买入仍要求原三项趋势恢复、进入原候选且有资金/名额。策略没有固定60日到期清仓，也没有把固定百分比止盈止损作为本轮退出依据。月内突发恶化无法由月度规则立即响应。

## 4. 小资金与整手分配

先保留允许持有的旧仓，再依排名为新股预约费用后期望利润为正的合法股数，最后联合优化现金、股数与交易费用。主板新买按100股及100股增量，不要求五只等额。

2024年5万元首轮实际买入：桂冠电力1400股/7938元，宁波港1700股/6086元，农业银行3000股/11010元，工商银行2600股/12454元，中国银行3100股/12431元，费用后现金31.08元。

**单股25%是额外的研究分配参数，并非交易所整手规则要求。** 高价股可以进入排名，但100股若超出现金或25%单股上限仍会被执行层拒绝。以5万元初始账户为例，单股上限约12500元，100股超过此金额就无法买入。该限制仍可能减少高价股选择，尚未证明25%最适合个人账户。

25%也不是每日硬限额：月度复核间价格波动可使权重漂移，近期收盘最大单股权重27.54%，全段31.76%。受阻或锁定股数也不能通过虚构卖出来满足上限。

## 7. 收益与改善的来源

近期5万元账户净利润28026.77元：农业银行9662.65、工商银行7679.15、中国银行6633.87、浦发1435.59、中信银行997.53元，五只银行股合计26408.79元，占总净利润94.23%。其他股票盈亏抵消后贡献较少。它说明当前收益具有明显银行股依赖，不能将绝对收益直接归为普适选股alpha；本轮也未完成相对可投资指数/银行基准的超额归因。

与baseline的增量收益是另一个口径：Hybrid近期多6669.92元，其中2024少146.36元、2025少73.31元、2026多6889.59元；中行、山东高速、桂冠电力贡献增量的87.25%。不能把“总利润银行贡献94%”与“相对基线增益三股贡献87%”混为一谈。

真实近期仅六次持有许可被新规则改变：三次多等、三次提前。仅A独立近期多赚5183.83元，仅P独立少赚1106.87元，组合多6669.92元；改变后续持仓与资金占用产生交互，不能称两项规则独立有效。

## 8. 仍未解决的风险

- 2022—2023，Hybrid收益62.86%与baseline62.93%近乎持平，但回撤15.57%差于13.57%。全段改善不等于每个环境都改善。
- 中行2026-07-01获准多等时仅高于MA120约0.0059%，折算原价距均线约0.033个报价单位。边界很薄，当前没有迟滞区间或安全缓冲。
- 长期收益、均线位置都是价格条件，不是基本面安全证明。固定原持仓中，多等的旧窗口四次事件随后20日都下跌；提前退出也可能错过反弹。
- 候选统一收益常数、银行集中、额外25%持仓限制及缺少主动现金判断仍未解决。五只股票不代表五份独立风险。
- 所有验证年份均被多轮研究接触，阈值与结构有适应历史的风险；没有新的前向实盘/纸面结果。

## 9. 成交假设与核验边界

研究费用为买入0.1%、卖出0.2%、每笔最低5元，属于本项目固定费用假设。当前额外slippage_rate为0；按下一交易日开盘及原现金、限价、成交量约束执行，未模拟盘口排队和完整市场冲击。费用翻倍不等于完成额外滑点或延迟压力检验。

按244交易日年化；Sharpe使用日收益均值/样本标准差乘√244，未扣无风险利率。每日总权益计量回撤，包含初始本金；现金分红应收、到账及送转按原公司行动账本处理。
