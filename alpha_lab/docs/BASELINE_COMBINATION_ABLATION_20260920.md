# 等权结果的固定消融协议

主实验完成后，已看到等权方案的结果。本补充明确属于解释性消融，不作独立样本外检验，不重新调参或改主实验选择。

使用主实验等权账户逐年锁定的调仓日、持股数、原基线年度因子参数与同一10万元连续账户，计算：

1. 只按原低换手分数选股，不加入其他因子的资格过滤。
2. 在上述分数上增加三条因子同时可得的资格交集，仍只按低换手排序。
3. 三因子等权重放，要求信号、持股数和四张账户表与主实验一致。

第一项与原低换手基线的差异对应频率/持股数改变，第二项与第一项对应资格交集，第三项与第二项对应排名混合。差值是这一固定干预顺序下的账户反事实，不能解释为相互独立、普遍可加的因果贡献。

不增加其他窗口、频率、持股数、权重或择优步骤。每个账户独立交易账本审计，并做三个年中截止点的原始信号与账户前缀检查。结果保存主实验目录下`posthoc_ablation/`，不覆盖主实验。
