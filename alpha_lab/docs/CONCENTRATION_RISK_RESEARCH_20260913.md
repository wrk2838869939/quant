# 少量股票组合集中风险：原始证据与两个有界假设

日期：2026-09-13。范围：0—5只主板股票、月度复核、整手、小资金、长期持有。只做文献与方法研究；没有改策略、训练或运行账户。本轮已接触2024—2026结果，下面的假设均属事后发现问题后的探索，不能将该窗口重新命名为独立OOS。

优先建议研究“新增仓位是否重复已有暴露”，保留低换手排序和趋势完好的旧持仓。收缩协方差适合作为风险估计工具，但没有论文证明它能让五只A股获得稳定超额；波动预算可以决定新增资金是否留现金，却不能保证最大回撤。不要直接移植多资产风险平价或50股HRP。

## 本地约束与已知污染

当前规则以 `configs/symmetric_phase_research.yaml` 和冻结执行器为准：全A合格池先做PIT排名，主板低换手优先，原Top20候选、最多五股、单股上限25%、月度复核及原整手预约；不因新研究改变原趋势退出。所有风险输入只能使用复核收盘及以前已知价格，订单仍按原下一可执行时点处理。

修复run为 `outputs/recent_low_turnover/20260913T090336_282870Z`。其 `input_coverage_audit/coverage_audit.json` 和 `coverage_gate.json` 认证57个月有特征/预测；旧run因四日daily_basic空数据导致13月无预测已作废。旧run的高现金不能算成功择时，也不能拿来校准新现金规则。修复后的近期结果已经读过，同样不是新OOS。

下面只保留两个研究假设。实际本轮登记为24 cases、相关约束与集体退出pause的2×2消融；第二项风险预算仅留作研究备选，未实施，也未加入本轮账户。

## 假设一：只限制新仓与已有仓位的高相关重复暴露

**可证伪命题：** 不替换趋势完好的旧持仓，按原Top20低换手顺序买入时，拒绝与保留/已预约股票高度相关的新候选，能减少可避免的同向集中，且不会仅靠长期少持股、少投入资金伪装改进。

本轮登记采用root提出的单一工程版本：最近120个已完成交易日的日收益Pearson相关，至少100个共同有限收益才可评价，任一对`rho > 0.7`则拒绝新增；`rho == 0.7`不拒绝。100/120同样是数据可用性的工程门槛，不是统计最优值；若要求120个完整收益则需121个有效收盘价格。逐候选复用原整手经济预约，只有预约成功的股票才进入后续相关约束集合；不改变原低换手顺序，不为降低相关主动卖旧仓，不要求凑满五只。已有三只同向银行若仍满足原持有规则，研究层只记录集中，不能追溯删除它们。

- **0.7的依据有限：** 检索未找到针对本任务的最优阈值证据。它只能作为预登记的“高度重复”工程界线，而非论文推荐值。若两股等波动、等权且相关0.7，其组合方差仍为单股的0.85，波动约为单股的0.922；这说明分散空间有限，不说明0.7优于0.6或0.8。假设五股等权等波动且两两相关0.7，方差对应的独立资产等效数仅约1.32；真实不等权组合不能照搬这个数。
- **120日的依据是沿用现有长窗口，减少新的自由参数，非统计最优。** Pearson相关有估计误差；独立近似下Fisher变换标准误为`1/sqrt(n-3)`，实际收益异方差、序列依赖会进一步削弱精度。保存每对相关、有效样本数和距离0.7的余量；置信区间只诊断，不再新增阈值规则。
- **未知不得当零相关：** 在统一的最近120收益日期内，任一所需对不足100个共同有限观测或为常数序列，就标记`unknown_correlation`，不准该候选新增；不得把停牌/缺价carry成零收益来获取虚假的分散。若保留股数据缺失导致所有候选不可判定，该月是风险数据未知，不是“市场无机会”。需单列未入场原因，不能与真实相关拒绝合并。
- **为何本轮不优先最小相关性重排序：** 它虽然没有0.7阈值，却把低换手优先改成相关优先；当全池高度相关时仍会挑“相对最小”并可能买满。改动混合了选股和暴露，且可能放大估计误差。硬拒绝对当前“只减少新添的重复风险”的问题更易追踪，代价是主观界线和更多现金，均需公开承认。

最小消融仅为原规则与该单版本，先不叠加波动现金轴。每次拒绝保存复核日期、候选原排名、触发的保留/预约股、相关值、实际预约金额、未用现金。报告真实原持仓而非只有当天理论Top5；实际不足五股时不能重归一成满仓。以固定当时持仓和真实价值权重做事件期价格代理诊断，同时报告完整账户；未来换股后的两条曲线差额不能全部归因相关分散。

**失败条件：** 相对基线没有降低后续已持仓共同下跌/集中损失，或改善仅来自平均敞口下降且收益现金拖累明显，不能声称发现相关性alpha。0.7附近频繁换判、单个银行事件决定全部差异也应判为不稳健线索。可以描述原版本被拒绝机会的后续结果，但不能按这些结果再改阈值。

## 假设二：用收缩协方差限制新增资金风险，剩余保留现金

**可证伪命题：** 在原选股、原旧仓退出完全相同的条件下，新增资金按账户风险预算缩小，能减少账户风险恶化；其效果应超过单纯较少投入股票的机械效果。本项与现金agent的方案择一统一，不能并行挑赢家。

实现思路：在复核收盘用过去120日收益估计保留股与原预约候选的协方差，固定一个收缩实现和目标；例如明确采用官方Ledoit–Wolf单位阵目标，而不混称恒定相关。不估计个股期望收益。设旧持仓实际权益权重为`h`，原新增预约权重为`b`，只允许共同倍率`a∈[0,1]`，求最大可用倍率使 `(h+a*b)'Σ(h+a*b)` 不超过预先登记的日方差预算。若没有可行倍率，停止新增并记录既有风险超预算；不虚称旧仓风险已得到控制。可行性不能假设风险随倍率必然单调，负协方差时二次函数可能先降后升。

方差预算需要在看本轮结果前明确登记。可采用用户既定风险额度；没有该额度时，可预先固定为2014—2018原规则月度候选篮子预测方差的中位数，统计程序和历史身份先封存。该数只是设计约定，不是“最优目标”；不能用2024—2026最大回撤反推出最漂亮目标。这里没有建议运行多组目标。

整数化沿用原整手预约，不突破原25%单股约束；倍率缩放后的订单须以实际整手权重重新检查风险与现金。舍入在负协方差时不保证组合风险单调下降；若超预算，按预定顺序进一步减少新增整手并重新检查，仍无法满足则不新增。交易费用由账户实际执行扣一次；风险矩阵使用收益代理不再额外扣同一成本。现金收益沿用原账户设定，不能假定未经执行的货币基金利息。

最小消融：原规则、固定现金比例的对照、该风险预算版本；固定比例必须只根据登记前历史确定，不得用评估期平均仓位事后匹配再称可交易对照。完整协方差与只保留同一矩阵对角线的差异可作为风险数值诊断，不另加一整套寻优账户。输出每月预计/实际风险、现金、整手拒绝、数据未知、净收益、回撤持续时间和再入场滞后。不要只以更低日波动判成功。

## 必须保留的解释边界

1. **低波不等于低回撤。** 平静期累积的信用/财务/退市风险、隔夜跳空和连续不可卖跌停，不会被小历史标准差消除；持续小跌也能造成很长回撤。低换手、低波、银行集中可能是同一类经济暴露，不能重复当作三份独立证据。
2. **相关升高不是卖出信号。** 同涨会提高相关；危机中的共同冲击可能比120日估计变化更快。相关限制是事前重复暴露控制，不能保证躲开下次下跌；上尾/下尾相关及行业因子共同暴露只作固定诊断，不临时加入第三策略。
3. **收缩不创造信息。** 股票少时主要问题可能是时变和跳跃风险，而非矩阵不可逆。自适应强度是估计公式，也仍需记录其稳定性；不得扫描目标、窗口和阈值后只留下最好版本。证券风险贡献均等不代表经济风险分散。
4. **整数与长期持有会压过理论权重。** 五万元中一手价格很高的股票可能改变整个风险预算；必须同时看两万/五万/十万原整手敏感性。价格不可买、现金不足、风险拒绝和输入未知必须分别记账。受阻的老仓只能按真实可卖条件处理。
5. **开发与验证隔离。** 2019—2021、2022—2023和当前2024—2026均已有研究接触，只能称历史复验/探索性压力测试。最终确定一版后向未来纸面记录；不得用已读窗口通过来宣称新OOS成功。所有收益结论必须来自修复后的可复现净账户；本文没有新增业绩结论。
