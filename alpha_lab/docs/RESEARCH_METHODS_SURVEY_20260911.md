## 2. 中文研究：重点学习实验拆解

### C1. 华泰《周频量价选股模型的组合优化实证》（2020-12-21）

**方法：** 先分解市场、行业、风格和特异收益，再构建与持有期匹配的风险预测，最后比较约束下的组合。第7页特别区分事前估计与使用未来数据的事后波动率偏误调整。

**应用：** 为现有持仓补充规模、流动性、波动率和行业归因；以真实股票权重及现金计算风险。月频策略不能直接套用周频协方差。事后残差收益只说明所选模型尚未解释它，不自动证明可交易 alpha。[券商原始PDF，重点第5–9、14–19页](https://crm.htsc.com.cn/doc/2020/10750101/e31d42ff-2b85-423f-b45b-8936cea1f4a0.pdf)

### C2. 华泰《再论时序交叉验证对抗过拟合》（2019-02-18）

**方法：** 按月份整体切分，避免普通按行切分把同一截面的股票分到训练和验证两侧；设置样本量相同的对照，分离“少用样本”和“保留时间顺序”的作用。

**应用：** 所有股票按信号日期分组；每个折重新做因子筛选、方向选择和权重估计。结合本项目前向标签，再剔除收益结束时间跨入验证区间的训练样本。只按日期切开仍不够。[原始PDF，重点第5–7页](https://crm.htsc.com.cn/doc/2019/10750101/ce6b61af-f34d-4ab4-9d7c-5a8f91edc1cd.pdf)

### C3. 华泰《基于CSCV框架的回测过拟合概率》（2019-06-17）

**方法：** 保存所有候选收益序列，观察在一组时间块中胜出的策略，在互补时间块中的排名是否落到后半区；区分模型训练过拟合与反复挑回测冠军。

**应用：** 补建完整候选矩阵，保留失败方案及人工选型过程。原报告也提示重排忽略路径依赖；有现金、持仓和延期成交的策略，不能把重排收益冒充一次可执行回测。[原始PDF，重点第5–10页及风险提示](https://crm.htsc.com.cn/doc/2019/10750101/9ee613ca-aff7-47a0-ab27-b3f448953585.pdf)

### C4. 华泰《因子合成方法实证分析》（2019-01-04）

**方法：** 比较等权、历史收益/IC加权、最大化ICIR、最大化IC和PCA，检验协方差估计及权重稳定性。

**应用：** 同时记录因子相关性、权重漂移、前50名重合度与实际换手。报告的分层多空目标与本项目纯多头不同，不能据此认定ICIR合成一定优于单因子；本仓库已经出现总体排序相似、买入名单却明显变化的情况。[原始PDF，重点方法及第11页](https://crm.htsc.com.cn/doc/2019/10750101/ae933a8c-5a94-4d92-8f33-d92b70c36119.pdf)

## 3. 英文研究：解释机制和统计边界

### E1. Amihud，Illiquidity and Stock Returns（2002）

用绝对收益除以成交金额衡量非流动性，讨论流动性溢价及其与小公司收益的关系。当前候选 Amihud 信号因此首先需要接受“流动性风险补偿”的解释检验。高信号也可能对应更贵、更难退出的股票。论文不是本项目20日版本有效的证据。[作者机构存档，实际阅读版本为2000年8月工作稿](https://archive.nyu.edu/jspui/bitstream/2451/27420/2/S-AM-00-10.pdf)

### E2. Liu、Stambaugh、Yuan，Size and Value in China（2019）

强调中国市场的因子构造需考虑制度背景；其规模因子排除最小30%公司，以处理历史壳价值影响，价值因子采用盈利价格比。应学习“改变微盘处理后结论是否保留”的检验，不能直接搬用30%阈值，也不能假设旧制度结论至今不变。[NBER原稿，2018年12月修订版](https://www.nber.org/system/files/working_papers/w24458/w24458.pdf)

### E3. Novy-Marx、Velikov，A Taxonomy of Anomalies and their Trading Costs（2016）

比较异常收益扣费后的表现及成本缓解方式；买入要求严于继续持有的缓冲规则，在其研究的简单方法中有效。启发是比较换仓的增量收益与成本，且必须控制组合分散度。我们的固定排名缓冲已经未能改善总体表现，文献不能推翻这个结果；美国样本的换手阈值也不能直接用作A股门槛。[作者原稿，2015年8月版本](https://mysimon.rochester.edu/novy-marx/research/ToAatTC.pdf)

### E4. Boyd等，Multi-Period Trading via Convex Optimization（2017）

把收益预测、风险、交易/持有成本和约束放进同一个决策问题，并考虑预测不确定性。适合借鉴其接口与目标设计：新预测只有覆盖额外成本及风险，才值得改变持仓。先做单期、少参数的版本；复杂优化不能补救不可靠的预期收益。[Stanford作者页面及论文](https://web.stanford.edu/~boyd/papers/cvx_portfolio.html)

### E5. Bailey、López de Prado，The Deflated Sharpe Ratio（2014）

DSR考虑多次选型、试验间Sharpe离散度、样本长度及收益偏度/峰度。试验次数应考虑依赖关系；台账行数不是独立尝试数。它也不能修复遗漏的人工选择或泄露。仓库当前实现与论文口径不符，详见第5节。[作者PDF，第8–9、14页](https://www.davidhbailey.com/dhbpapers/deflated-sharpe.pdf)

### E6. Bailey等，The Probability of Backtest Overfitting

CSCV通过互补子样本检查“样本内冠军”的样本外相对排名，估计给定候选集合的选型不稳定性。它不同于按时间向前训练，也不等于策略未来亏损概率。先保留完整实验集合，再把PBO作为辅助诊断；不能用低PBO把反复使用的开发窗口恢复成新样本。[作者2015年2月修订稿](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)

## 5. 对照源码发现的具体缺口

### 5.1 DSR统计量有可复现的尺度错误

`src/ledger.py::deflated_sharpe` 用 `std(rets)/sqrt(n)` 同时充当试验间Sharpe离散度和检验标准误；`n_obs`未参与计算，偏度/峰度未使用。函数返回值约定还是“越小越显著”，后续必须明确它与论文DSR方向的关系。

合成数据检查：同一收益序列乘正数100，Sharpe保持0.035925，当前函数输出却从0变为0.783147。输入的收益单位改变就影响结论，说明其输出不能承担显著性判断。[复核结果](../outputs/methods_survey_20260911/dsr_scale_probe.json)

复现（在alpha_lab目录，不读取行情）：

```python
import sys
import numpy as np
sys.path.insert(0, "src")
from ledger import deflated_sharpe
r = np.random.default_rng(20260911).normal(.0003, .01, 1000)
sr = r.mean() / r.std(ddof=1)
for scale in (1, 100):
    print(scale, deflated_sharpe(sr, len(r), 20, rets=r * scale))
```

**修复验收建议：** 样本频率一致；区分收益分布与试验间Sharpe分布；收益正比例缩放不改变检验结果；长度、非正态修正与试验依赖显式处理；数据不足时返回“无法评估”。不能简单把台账行数代入后宣告通过。

### 5.2 中性化存在静默退回原值的分支

`src/neutralize.py::neutralize` 在有效样本少于50时原样返回因子，其他截面则输出回归残差。两种语义可能混入同一报告。此为源码事实，尚未统计真实数据中的触发频率。

建议增加 `neutralization_status`、有效样本数与行业覆盖，失败日不得标为“已中性化”。当前已有的板块归因不是完整行业/风格归因。

### 5.3 选型指标、预算筛选与风险尚未完全闭合

`prepare_long_only_followup.py` 的信号选择基于TRAIN前50毛收益代理，最终可投资名单还受到资金、价格及板块最小股数影响。因此低资金方案不是原方案简单减半，Sharpe变化也不能全部归功于现金储备。

已有成本翻倍压力只是费率压力，不包含所有价差、冲击、延期成交与退出受阻风险。相关工程模块是 `investable.py`、`portfolio.py`、`factor_blend.py` 和 `report_investability.py`。

## 6. 可执行的下一阶段顺序

以下为调研后的方案，尚未实施，参数不能在2022–2023反复挑选。

| 优先级 | 工作与明确产物 | 如何决定是否继续 |
|---|---|---|
| P0 | 修复统计口径；中性化失败显式标记；统一实验ID、父实验、代码/数据哈希、人工选择记录 | 先通过尺度、时间边界和失败分支测试，禁止旧DSR作准入依据 |
| P1 | `factor_diagnostics`：前端毛/净收益、同池同预算对照、规模/流动性/行业/板块暴露、缺失与不可成交归因 | 若同风格对照已经解释大部分利润，把它归类为风格策略；不继续包装成独立选股收益 |
| P2 | `risk_forecast`：滞后暴露＋收缩协方差，分别记录预测20日风险与随后实现风险 | 先检验风险预测偏差、覆盖和稳定性；未经校准，不用它决定资金比例 |
| P3 | `trade_optimizer`：已有持仓出发的收益—风险—成本优化，再由原账本执行整数股订单 | 与同信号、同资金、同风格约束的等权方案比；实际费后改善才能保留 |
| P4 | `walk_forward`及前向纸面记录：全部训练操作在时间折内完成，保存每次决策时可见输入 | 历史重构只能给回溯稳健性证据；真正新证据来自冻结后尚未观察的数据 |

### P1：先回答利润来自哪里

固定比较原信号与规模、行业、板块匹配的对照池，再增加流动性匹配，观察解释增量。对照也使用相同资金预算、股票数量、现金政策、下一交易时点和撮合规则。按年报告，并列出最大盈利/亏损股票、退市损失、无法退出天数。

同规模内的信号收益、双重分组以及残差分析应并列呈现；不能只保留最漂亮的一种中性化结果。控制流动性后收益消失，可能说明风险补偿而非实现错误；需结合危机月份和退出成本解释。

### P2–P3：把可交易预测转成持仓

概念目标为 `预期收益 − 风险惩罚 − 交易成本 − 预测不确定性惩罚`。分数需在历史时间折内校准到同期限收益单位，不能把rank直接视为收益率。最初可用收缩的分组均值，对不稳定预测降低权重。

股票和现金权重合计为1，费用必须预留；限价受阻或T+1锁定的持仓作为实际约束。连续优化后要做整数股与预算复核，并记录“理论目标→可提交订单→实际成交”的差异。危机期间的流动性恶化可先做情景压力，不能把无成交数据的冲击参数称为已校准。

固定信号后依次比较等权、仅风险约束、仅成本控制、两者同时存在四种机制；同时报告收益、回撤、Sharpe、实际仓位、换手与风格变化。降低回撤若仅来自减少股票敞口，需要明确说明。

### P4：验证的是整个研究流程

所有因子方向、筛选、合成权重、收益校准及风险参数都只能用该折当时可见的数据。切分按交易日期分组，使用实际标签结束时间清除跨界样本，并保留既定隔离间隔。测试未来行被替换后，历史信号和持仓应不变。

2014–2023可重构多个向前时间折，但这些历史已参与研究，必须标为回溯诊断；2024+保持冻结，不为本计划重新查看。CSCV/PBO是候选选型诊断，不能替代上述时间顺序验证。前向纸面期先冻结代码、候选和评估规则，记录失败订单、公司行动、预测风险与实际结果；不能在观察后追改起点。
