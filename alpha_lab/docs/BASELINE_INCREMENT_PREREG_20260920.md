# 基线＋监督学习增量：执行前登记

本轮实际训练岭回归和浅层LightGBM，比较对未来排名直接建模与在已有基线排名上拟合修正。冻结数据、账户、基线内部参数和交易政策，不改变资金或回测引擎。

## 表示与学习

四个宿主为已登记低换手、低波/振幅、估值和上一轮等权对照。每折使用宿主当年已登记的因子参数、频率、持股数和资格；等权政策来自上一轮内层锁定记录。资格只依赖宿主原有分数是否可得，其他模型输入缺失不额外删除股票。

输入是三条规则的当日截面百分位排名和宿主排名，中心化并附缺失标记。目标为宿主可得股票中未来5/20日收益的截面排名：从下一交易日开盘至第H个交易日收盘，完整路径且标签结束严格早于拟合日。逐日训练权重总和相同。

直接模型学习target；增量模型学习target-host_rank。两者同一模型规格、样本、标签期限、输入、权重和拟合日。增量分数为host_rank + amplitude * clip(predicted_delta, -1, 1)。amplitude为零时直接返回原始宿主分数，不能经过重排名或模型缺失处理。缺训练历史时保留宿主排序。

训练窗口504个市场交易日，季度重训；岭回归alpha=1/100，LightGBM叶数3/7（其余参数固定），标签期限5/20，共8组模型规格。幅度完整枚举0、0.05、0.1、0.2、0.4、0.8、1，不假设局部单调。

## 时间顺序和选择

内层从2020年开始，2019年提供初始训练；2021/2022/2023评价折只用此前截止年末数据选规格和幅度，内层预测同样按季度滚动训练。宿主内部参数本身按该内层历史选择，故不把内层预测当作完全未参与任何选择的数据。

每宿主每折候选：1个原样宿主、8×6个非零幅度增量、8个直接模型，共57个；四宿主三折合计684个账户候选，96条成对模型滚动训练路径。每个拟合时点同时训练直接和增量模型。

共同账户目标为内层自然年净年化收益中位数，连续及逐年回撤不超过30%，且有买入。五条评价路径：

- baseline：原样宿主。
- residual_best：在原样宿主与所有增量中选目标最大者；并列优先较小幅度、较低换手、固定ID。
- residual_stable：收益距离最优不超过0.5pp且不低于可行宿主；所有近优候选都有足够实测幅度邻居时优先邻域下四分位，否则优先较小幅度。
- direct_best：直接模型中选最优可行者；无可行者持现金。
- direct_with_fallback：直接模型加原样宿主共同选择。

没有可行候选则现金，不放宽回撤线。所有年度规格和幅度在计算外层账户前落盘；外层资金与持仓跨年连续。季度内模型固定，季度重训只用当时已经成熟的标签。

## 必须核验

原样宿主四张账户表与旧档案一致；增量零返回原分数，拟合故障不能静默丢弃。每个模型保存并重载验证首日预测。保存全部训练时点、最大标签结束日、模型系数/重要性、分数及账户过程数据。每个候选独立账本核验。最终账户三个年中截止点重新截断原始输入、重建特征、重新训练/预测，并核对信号和账户前缀。

所有候选和失败计入记录。报告按宿主配对，不在观察本轮外层后重新挑宿主或幅度。上一轮等权与基线已经看过外层，本轮仍是同一93股工程样本上的开发诊断，不能宣称独立样本外技能。
