# 基线初始化完整策略学习：首轮执行登记

方向依据：BASELINE_INITIALIZED_POLICY_LEARNING_20260920.md。本轮不是收益排名监督预测，也不限制为基线的小残差。

冻结原93股数据、费用、10万元、30%回撤验收阈值。原 portfolio.py、基线注册表与既有结果不改。独立 policy_portfolio.py 复制原执行循环，收盘后只给模型当时账户副本，下日开盘执行。保留真实公司行动、现金、整手、T+1、涨跌停和拒单。新股不得突破共同冻结资格。策略可解除基线自身的估值/因子可用性过滤。

输入：已有23个因子的当日截面排名与缺失、4个初始策略评分和可用性、实际持仓比例/可卖量/持有时间/持仓价格变动/待售/成交拒单反馈、现金/历史峰值回撤/账户变化、日周月日历。16单元共享隐层，5个股票动作头、3个全局动作头，含可训练线性通路以精确编译基线。全部参数参与演化，维度由代码实际计算。4条初始化策略分别对应低换手、低波/振幅、估值、等权。初始账户轨迹必须与归档逐表一致；评分可用等序排名而不是相同数值。

动作：调仓或不动、评分及买入资格、持有或退出、整手减仓、1至5只股票、可用现金投入比例及新仓预算权重。首版沿用不对已有持仓加仓的执行边界，长期保持仓位仍可通过保留、减仓、退出后重入变化。5只上限是首版显式架构限制。股票数和筛选等硬决策不可导，因此使用真实账本回报的演化优化。

预登记预算：每年度每宿主2种初始化（基线/随机），各1次初始评价+8代×12个候选=97次训练账户；另初始点及8个每代冠军各1次验证账户=9次。4宿主×2初始化×3年度，共2328次训练+216次验证。相同结构、数据、评价预算和成对扰动种子，随机组不读取宿主的初始化动作参数。每代以净收益和可行性排序，更新精英加权中心，交替在中心和历史冠军周围用三个尺度正负扰动；成功率调整尺度，无永久基线距离限制。所有网络块均扰动，允许过滤、频率和排序发生大幅变化。此为有限预算演化原型，不宣称实现完整 CMA-ES 或全局最优。

年度2021/2022/2023：训练2019至外层年前第二年末（2019/2020/2021），验证前一整年（2020/2021/2022），只锁定验证可行方案。训练优先完整账户MDD及逐年MDD均≤30%且至少有买单，其次最大扣费净收益；验证同判据选净收益最高者，均失败则现金。训练末未清仓，期末按市值结算；每个训练/验证回放10万重置。最终2021—2023外层账户连续，年度只换模型不重置账户。所有年度参数先锁定再打开外层结果。

重要限制：基线初始化参数本已用截至外层前一年历史筛选，因此验证年曾参与基线形成，并非完全独立验证。原93股存在全期质量隔离偏差；全历史已被此前研究观察，本轮外层仍不是新鲜无偏样本外。训练优于初值不代表跨期提升。30%为历史结果验收，不保证下一日成交或最大损失。

验收：四初值逐表复现、因果原始数据截断+账户前缀一致、相同参数重复回放、可显著脱离基线的动作覆盖、独立账本审计、每次评价和每代参数/选取依据存档。最后报告实际行为改变和随机对照，不按外层结果改预算或重选冠军。
