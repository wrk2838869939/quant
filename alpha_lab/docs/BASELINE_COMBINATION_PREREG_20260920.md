# 基线包含性与组合目标诊断：执行前协议

本轮回答：将三条原样基线纳入候选后，组合权重学习能否保留基线；在完全相同候选中，用预测IC或扣费账户目标选择，会出现什么差别？冻结数据、账户与原基线不变。

## 时序与候选

2021/2022/2023三折，每折训练从2019年初到上一年末。基线内部窗口、过滤、频率、持股数使用既有登记中该外层年度的参数；它们本已由截止上一年末的数据选择。训练期重算这些参数下的信号是拟合过程，不冒充当年的实时历史策略。选择完成并落盘后才构造外层信号；外层跨年账户连续。

三个非负权重总和为1，步长0.1的完整三角网格，共66组，再加入三等权。非顶点分别交叉当折基线中去重后的(频率,持股数)组合；顶点强制保留对应基线全部定义，不能换频率或持股数。零权重因子不参与过滤；正权因子先各自做当日截面百分位排名，再取资格交集加权。顶点直接返回原始分数，核对分数、日期、持股数、四张账户表，防止只在公式形式上包含基线。

## 六条预先登记的选择路径

共同可行约束：连续账户及每自然年回撤不超过30%，有买入。账户目标为各年净年化收益中位数；完全并列按低换手、较少非零权重、ID排序。不是要求每年收益为正。

1. baseline_selector：只在三个原样端点中按账户目标选择。
2. account_best：所有可行候选中账户目标最大者，显式断言不低于可行端点最优值。
3. account_stable：在最优值0.5个百分点以内且不低于端点最优值的候选中，所有候选均有至少3个实测邻居时优先邻域收益下四分位；否则按低换手等破同分。邻居必须同频率/持股数、权重移动一步，不推断未测试点。
4. ic_best：同一可行候选集，选择平均日截面Spearman IC最高者。标签为次日开盘至20交易日后收盘，完整价格路径且标签结束日严格早于外层开始，只在真实决策日计算IC。它与旧IC比例配权不是同一算法，本轮用于隔离选择目标。
5. ic_with_baseline_fallback：把ic_best与三个端点再次按账户目标比较，不能因为“已经学习”而拒绝退回规则。
6. equal_weight：固定三等权，只对当折已登记的频率/持股数按账户目标选取；无可行候选则持现金。

无可行候选保留现金方案，不放宽风险线。新增账户目标/IC目标路径是有限候选空间上的经验权重学习；本轮不训练新的神经网络。

## 必须产出

保存全部候选配置、分数、持股数、四张账户表、内层分年指标、独立交易账本审计、IC与标签结束时点、锁定选择、外层连续净值。输出实测邻域及沿两权重转移的三点非单调表；风险不合格点仍完整保留。外层选中策略及三个固定基线做三个截断日期的原始特征重建和账户前缀复验。

三条机制由既有外层结果挑出，93股还有全期质量隔离偏差。本轮只能诊断和开发，不能宣称新的独立样本外有效性。内层不劣于基线的性质不延伸到未来；30%是回测验收线，不是保证成交的强平线。所有参数及方法在观察本轮结果前登记于`configs/baseline_combination_v1.yaml`。
