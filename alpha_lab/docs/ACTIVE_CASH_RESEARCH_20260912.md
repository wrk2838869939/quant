# 小资金账户的主动空仓：研究与旧代码审查

日期：2026-09-12。目标是风险升高时减少股票敞口，允许完全持币，并能重新入场。本文不采信旧文档收益，也不宣称任何新择时规则已经有效。当前工作：原始文献调研、旧函数合成路径复现、现有账本过程归因；尚未完成新风险规则的历史成交回放。

后续进展：[首轮状态与成交验证](ACTIVE_CASH_VALIDATION_20260912.md)已完成；以下保留当时调研状态。

## 1. 为什么研究整体避险

重建既有2022—2023开发账本的逐股每日利润，最大逐日对账误差为7.3e-11元。其最大回撤区间为2022-03-03至04-28：累计损失18,511.70元，涉及97只股票，其中81只累计亏损；最差5只损失3,172.91元，仅占净损失17.14%。最差单日04-25有46只亏损、4只盈利。

这是广泛共同下跌的线索，支持检查市场/风格层风险，**尚不证明风险可预测，也不能据此归因于某一个宏观因子**。该账本本身有等额预算价格过滤，不能直接当作个人账户方案。详细数据见[过程审计](RETAIL_PROCESS_AUDIT_20260912.md)。

## 2. 文献中值得迁移的方法

以下只学习机制和检验方法，不照搬论文收益。五份原始PDF与SHA256保存在`outputs/active_cash_research_20260912/sources.json`；Faber仅取得SSRN摘要，全文下载失败，证据等级单独标明。

| 研究 | 方法与可迁移部分 | 在本项目中的限制 |
|---|---|---|
| Moreira、Muir，2016工作论文/2017发表，[Volatility-Managed Portfolios](https://www.nber.org/papers/w22208) | 用已实现波动估计下一期风险，风险升高时降低敞口 | 逆方差缩放不等于主动清仓；不可照搬杠杆或全样本缩放常数 |
| Cederburg等，2020，[On the performance of volatility-managed portfolios](https://www.lehigh.edu/~xuy219/research/COWY.pdf) | 对103种股票策略检验；区分回归中的正alpha与实时可实施效果 | 样本外并未系统性胜出。它提供的是反证：波动率择时也必须重新验证 |
| Bongaerts等，2020，[Conditional Volatility Targeting](https://repub.eur.nl/pub/130215/Bongaerts-Kang-van-Dijk-Conditional-volatility-targeting-2020-FAJ.pdf) | 只在极端波动状态调整敞口，减少普通波动中的频繁调仓；明确排除事后缩放 | 原研究涉及指数期货、杠杆和低交易成本；仅借鉴“异常状态才动作”，不照搬成本或倍数 |
| 华泰，2019-09-27，[波动率与换手率构造牛熊指标](https://crm.htsc.com.cn/doc/2019/10750101/465187f1-0ae9-416e-b817-65d786a2e0d2.pdf) | 联合观察波动与交易活跃度，区分放量上涨和风险恶化；指标为波动率/平均换手率 | 同期状态相关性不是未来预测力；长窗口可能慢，换手率分母须一致 |
| 华泰，2020-04-07，[牛熊指标在择时轮动中的应用探讨](https://crm.htsc.com.cn/doc/2020/10750101/9ae949c5-07ef-4057-a8c9-84ab3047835f.pdf) | 研究指数、行业、个股三个层次；用成分股看多比例决定总敞口，并通过分档减少换仓；包含CSCV参数过拟合检验 | **本篇将指标改成平均换手率/波动率，是2019定义的倒数**。必须核对方向；个股信号比例用于风险监控，不要求买入全部成分股 |
| Faber，2007/2013更新，[A Quantitative Approach to Tactical Asset Allocation](https://papers.ssrn.com/sol3/Papers.cfm?abstract_id=962461) | 简单趋势择时与现金配置可作为易解释对照 | 此次仅核实作者摘要，未获取全文；不据此确定均线参数或声称已完整复现 |

上述证据支持优先验证**趋势恶化、市场广度恶化和极端下行波动**，而不是马上训练复杂牛熊分类器。这是项目研究顺序的判断，不是论文已经证明A股小账户有效。

## 3. 旧版本实际做了什么

只查源码；未运行会读取2024年以后行情的旧入口。

- `audit/scripts/regime_compare.py::sig_v14`：过去60个日收益的中位数小于−0.2%，且当日上涨比例小于45%时禁止持仓。这里的中位数**不是60日累计收益**。本函数没有panic分支。
- `kcb_v18/scripts/kcb_v17_backtest.py::_classify_v14`：另外包含panic逻辑，滚动窗口最低只需10日；与上述审计函数并非同一规则。不能因同名“v14”而视为同一实验。
- `kcb_v15/src/market/regime.py`：趋势、广度动量、短长波动率比、恐慌与冷却期。应拆开验证每个条件的贡献，不能把所有条件合成一套后只看最终收益。
- `a_share_v18/src/rotation/sector_backtest.py:637`：`emergency_clear`设置空板块列表并停止新开仓；该分支不生成已有持仓清算订单。已有仓位仍依赖前面的退出逻辑。**停止买入与主动清仓不同**。
- 同文件`_classify_dynamic`：序数状态、广度比例、原始i20使用同一个`>0.5`映射。i20是小数收益时，这意味着超过50%才通过，与序数bull=1的含义不一致。滚动IC选择和信号执行之间存在尺度问题。
- 动态IC样本最后一个标签从`t-3`延伸至`t`。收盘后决策、次日成交时可以已知；如果声称`t`之前已知或用于当日盘中，就不成立。需要按实际时间戳核对，不能笼统称为泄露或无泄露。

## 4. 适合小账户的风险控制设计

风险判断与选股排序、整手分配分开。风险层输出股票敞口上限，可以为0；分配层保留高价候选，按整个账户现金和明确风险上限联合决定不等权股数。持仓数是结果或上限，不是必须填满的目标。

不需要先精准预测市场收益，才有资格设置风险预算。但要声称“主动空仓能改善收益”，必须证明警报之后确有可规避损失，且超过错过反弹和交易成本。**收益优势不足而持币**与**风险超预算而撤退**是两个独立理由，不能用正的因子排名替代任一个判断。

先比较三个简单信号族，不组合扫参：

1. **趋势与广度**：宽基趋势之外，同时观察PIT股票池站上均线比例、下跌扩散、候选池/已有持仓所属风格的恶化。广度不要求实际持有这些股票；避免仅用大盘指数掩盖小盘风险。
2. **极端下行风险**：下行波动、波动突升、跌停扩散及成交条件。普通波动只监控；明确异常才降仓或请求清仓。分位阈值只能来自过去窗口。波动升高也可能是反弹，不能自动等同下跌。
3. **账户风险预算**：实际净值回撤和估计尾部损失触及明确风险限额时降敞口。回撤触发是损失发生后的保险，不能包装成提前预测；金额和限额不能由“资金÷股票数”偷偷代替。

阈值、风险预算、确认天数尚未定稿，不把10只、半仓、固定百分比当作用户已确认约束。

### 退出与重入必须成对设计

`正常 → 观察 → 待退出 → 现金 → 恢复入场`。状态转换记录信号时间、原因、目标敞口、实际敞口、可卖股数和延期原因。`待退出`不能直接记成`现金`；涨跌停、停牌、T+1约束必须进实际账本。

恢复不能只等账户净值上涨：空仓后净值不会随股市恢复。需要持续计算市场和原候选池的影子状态，预先定义恢复条件与信号有效期。进入和退出可使用不同阈值/确认期减少来回切换，但须比较其造成的反弹延迟。月频选股不意味着风险检查或重入也只能每月一次。

现金至少分为：风险主动空仓、机会不足、整手余款、订单受阻和固定研究留存。小单滑点应依据价差、时段和成交参与率评估，佣金按真实订单计；不能沿用机构冲击成本，也不能假定危机时零滑点。

## 5. 验证先看完整事件过程

每个警报建立一行事件档案，并链接其逐日状态：

- 警报前：趋势、广度、波动、持仓相关性、已发生损失；是否仅在暴跌后触发。
- 执行：首次可执行时点、实际退出完成时点、退出前额外损失、未卖出仓位及原因。
- 空仓：持续多久，原持仓/冻结无择时对照在同区间涨跌，规避损失与错过上涨分别多少。
- 重入：触发原因、成交成本、距离恢复起点的延迟；后续是否反复出入。
- 失败：假警报、未警报的下跌、长期不重入，全部保留，不能只展示成功逃顶事件。

使用相同选股信号、初始现金和可成交约束的无择时分支独立回放。持仓路径会分叉，不能简单用“原净值日收益×0/1”替代现金/股数账本。对照还应有固定降仓，辨别改善究竟来自时机选择还是平均少持仓；若固定比例取自事后平均敞口，须标为归因对照而非可交易策略。

主要评价：极端损失、回撤深度/持续期、警报后的可实现损失规避、漏报/误报、重入踏空、换手和费用；收益与Sharpe作为补充。收益预测训练与风险标签均须避开未成熟未来窗口；重叠事件按连续风险段聚合，不当作独立样本。

开发纪律：2014—2021按时间滚动拟合/验证；2022—2023已经反复使用，只作开发事件诊断；2024+ TEST继续冻结。先注册少量规则与淘汰条件，再执行。当前没有新风险策略的业绩表，也没有“已经能逃顶”的结论。
