# 主动空仓首轮验证：风险触发与恢复时点

## 结论与范围

本轮完成三组固定规则的真实现金/股数回放。没有发现可直接采用的规则；最清楚的问题是**警报偏向识别已经发生的损失，恢复又把风险条件暂时消失当成可以买回**。这是具体实现与样本的诊断，不是“主动空仓无效”的普遍结论。

所有规则先写入`configs/active_cash_audit.yaml`并冻结manifest，之后才计算结果；未根据结果改阈值。市场特征读取2014—2023主板PIT面板；绩效仅覆盖反复使用的2022—2023开发窗口，2024+ TEST未读取。风险指标的市场代理是当日合资格主板股票平均收益，不是可交易指数；它和旧科创50研究的数据载体不同。

为隔离撤退机制，沿用已经冻结的选股及旧分席分配账本，研究总资金21万元、活动资金10.5万元。**这不是已确认的用户资金，也不是50只个人账户方案的重新推荐。** 旧价格过滤和分配缺陷仍限制结果迁移。

## 1. 固定规则及实际执行

| 规则 | 收盘时请求退出的条件 | 恢复条件 |
|---|---|---|
| 旧v14条件迁移 | 市场代理60个日收益中位数 < −0.2%，且当日上涨比例 < 45% | 连续3日不再满足退出条件 |
| 趋势＋广度 | 市场代理20日累计收益 < 0，且站上20日均线的合资格股票比例 < 40% | 同上 |
| 极端下行状态 | 市场代理20日波动率高于过去252日的80%分位，且5日收益 < 0 | 同上 |

分位阈值不含当日，更不使用全样本分位；窗口和阈值是首轮研究假设，并非已验证最优。市场资格按历史上市日、ST区间、有效成交和退市日判断，不按股价预算或因子分数筛市场广度。

收盘决策T只能在T+1开盘生效。风险退出覆盖已有仓位；停牌、跌停或红股锁定会进入`exit_pending`，不能记成现金。恢复期间不取消未完成卖单。撤退完成后可在月度调仓之间重新入场，沿用最近已知选股信号，最多有效21个交易日；过期等待新信号。恢复下单用最近一日成交量作容量约束，不用陈旧选股日成交量。

## 2. 警报前后实际发生了什么

| 过程指标 | 旧v14条件 | 趋势＋广度 | 极端下行 |
|---|---:|---:|---:|
| 撤退请求 | 0 | 15 | 11 |
| 请求现金的交易日数 | 0 | 202 | 64 |
| 完整观察到重新买入的事件 | 0 | 14 | 11 |
| 完整事件中，同期账户收益差为正 | — | 2/14 | 2/11 |
| 请求后5日，无择时账本继续下跌 | — | 7/15 | 4/11 |
| 请求后5日，无择时账本平均收益 | — | +0.033% | +0.567% |
| 警报前5日，无择时账本平均收益 | — | −1.078% | −0.717% |
| 无择时账本最差10天，当日最终处于现金 | 0 | 3 | 2 |
| 待退出但尚有仓位的交易日 | 0 | 2 | 0 |

无择时账本所有可观察5日窗口平均+0.179%，负收益窗口占44.05%。窗口重叠，警报数量少，以上不作显著性推断。完整事件收益差来自两套各自演进的真实持仓账本；不能称为保持完全相同股票后的纯择时alpha。日末现金也不必然表示开盘前没有隔夜敞口，`stress_days.csv`另列前日收盘暴露。

旧v14在本窗口不动作的直接原因：60日日收益中位数最小仅−0.1976366%，没有达到−0.2%。这说明移植阈值的尺度需验证，**不据此把阈值向观测最小值调整**。

趋势＋广度的请求有时确实先于进一步下跌，但退出到恢复的完整周期通常没有留下收益优势。仅看警报后短期是否还跌，容易忽略其后反弹与重入成本。

## 3. 一笔能解释问题的往返

极端下行规则在2022年4月：

1. **4月20日收盘**：5日市场代理收益仍为−0.6085%，但20日波动率降到1.2113%，低于历史门槛1.3356%。连续3日未满足“高波动且下跌”，系统恢复允许持仓。
2. **4月21日开盘**：实际买入47只，成交额65,850.20元、费用235元。使用的是4月7日已知选股信号，未伪造当日新信号。
3. **4月21日收盘**：市场代理5日收益变为−5.3530%，波动率升至1.4479%，重新超过门槛1.3356%，再次请求退出。
4. **4月22日开盘**：卖出全部47只，成交额63,584.20元、费用235元。此间无分红权益影响，净亏损**2,736元，其中费用470元**。

它随后避开了4月25日的大跌，但已经在一次错误重入里先损失了资金。这里的恢复依据只是“暂时不符合极端风险条件”，没有正面的恢复证据。退出规则与重入规则共用条件反面，是可定位的设计缺口。

另一个例子：趋势＋广度在2022-10-31退出、11-04买回；对应区间无择时账本上涨3.200%，风险账本仅上涨0.163%。这类踏空不能被“成功空仓几天”的计数隐藏。

## 4. 费用与最终指标用于核对

| 方案 | 年化收益 | 最大回撤 | Sharpe | 费用（元） | 平均股票敞口 |
|---|---:|---:|---:|---:|---:|
| 无择时冻结账本 | 9.00% | −8.67% | 0.94 | 6,895 | 45.91% |
| 旧v14条件 | 9.00% | −8.67% | 0.94 | 6,895 | 45.91% |
| 趋势＋广度 | 0.07% | −5.78% | 0.04 | 10,243 | 23.99% |
| 极端下行 | 2.81% | −9.08% | 0.40 | 11,697 | 36.23% |

趋势＋广度期末利润比对照少38,863.69元，额外账面费用3,348.35元，占差额8.62%；极端下行少27,291.36元，额外费用4,802.08元，占17.60%。这是账面拆分，不是费用清零后重新交易的反事实。**仅降低手续费不足以解释或消除大部分差距**；实际券商佣金、价差及滑点仍未确认。

另跑了事前固定活动资金减半的对照，但它平均股票敞口从45.91%降到了8.38%，并未实现半敞口。旧“资金÷50”整手分配使大量订单买不了一手，故该对照**不能用来证明主动择时优于或劣于等风险被动减仓**。输出保留为分配层诊断，不作为有效风险匹配基准。

## 6. 后续研究的具体约束

下一轮应分别检验**风险会持续的证据**与**风险已经恢复的证据**，不再直接用退出条件的反面重入。恢复时也需检查原选股信号是否仍有意义，而非只判断它没有过期。这些是假设，必须先在2014—2021时间滚动实验中验证；不能围绕已看到的4月21日事例调参，再称为样本外成功。

小账户整手联合分配尚需接入真实旧仓调仓，并建立有效的固定风险暴露对照。现有结果不支持承诺实盘收益，但已把问题从“选哪个旧regime”定位到可测的触发尺度、恢复条件、信号陈旧与现金实现过程。
