# 实盘准备第一阶段：每日计划与账户闭环验收

日期：2026-09-14。最终运行：`outputs/shadow_execution/20260914T054517_770961Z`。

## 本轮结果

已将原 `Hybrid + full_risk` 从历史回放推进到独立的每日计划、账户状态和成交导入接口。它能只用截至今日的输入与独立交易日历生成明日计划，接收已有持仓，并在进程重启后接续。执行方式暂按手工下单、导入券商流水设计，没有连接或发送任何券商委托。

本轮是工程能力改进，没有改变选股和退出规则，也没有新增收益改善结论。恢复旧仓、整手缓冲保持关闭；五股、100股买入和原25%单股配置上限继续沿用。策略有效性与银行共同风险的审查结论仍然有效，当前仍不能直接自动实盘上线。

## 新增能力

| 能力 | 实现及约束 |
| --- | --- |
| 当日计划 | `src/shadow_planner.py` 输入账户快照、信号、日历与策略记忆，输出固定股数、DAY限价和预算；不读取明日OHLC，不预支卖款 |
| 账户接续 | `src/shadow_account.py` 使用SQLite事务、WAL和唯一编号保存快照、计划、订单、成交与审计事件 |
| 重复运行 | 同日同输入得到相同计划；同日输入改变拒绝覆盖；相同成交回报号重复导入不重复记账 |
| 部分成交 | 实际成交逐笔记账，支持不足100股的部分成交；剩余订单须有撤单、拒单或失效凭据，不自行推定成交或撤单 |
| 次日补位 | 仅真实卖出回报到账后按原规则补位一次；未卖完的风险目标保留，不因重启丢失 |
| 盘前检查 | 核对账户、完整持仓、未结订单、现金、可卖量、涨跌停、公司行动及券商限价合法性；通过只标记ready，不发送委托 |
| 当日信号 | `src/shadow_inputs.py` 从完整全A历史重建排名、Hybrid持有许可和年度风险折扣；过滤未来价格，不沿用过期年度模型 |
| 操作入口 | `scripts/shadow_execution.py` 提供快照、构建输入、计划、盘前检查、成交、终态、调整、状态查询；JSON导出避免静默覆盖 |

交易状态和信号计算分离。未入选候选的预约现金等审计缺值保存为JSON `null`，并非用零补造收益；订单金额和风险输入仍要求有效数值。

| 2022启动、月初、5万元 | 1,134 | 89 | 同上 |

对照使用冻结历史账户的每日收盘快照及已发生成交，验证新计划器在同样状态下是否给出同样订单。它没有声称重现券商队列成交；两账户互相重叠，也不是两份独立市场收益证据。最后一个研究行情日没有原版次日计划，因此不纳入这项订单比较；新接口末日规划由专门测试验证。

### 2. 不复用旧排名的全市场重建

截至2026-09-01的输入含5,814个历史证券代码，并非这些股票当天都可买。新构建器重新计算全截面，再施加主板与趋势筛选：Top20排名和当次持有许可与冻结版本完全一致，实际候选/持仓风险折扣差异小于1e-12。

已对未来价格扰动、收盘前回执、缺少当日数据、行数不符、模型年份不符和公司行动公告时点进行测试。该历史重建与合成对抗测试不等于新数据供应商首发版本已认证。

### 3. 23项测试通过

覆盖最后行情日生成次日计划、现金与五股/T+1约束、待卖款不可用于买单、部分成交、重复成交、并发重复规划、重启后同一计划、同日输入冲突、超量与限价异常、未结委托、快照资金差异、未来资金不能回灌旧快照、盘前持仓变化、预约审计缺值序列化及输入时序。

全程通过停止或回滚处理不一致，没有静默改变已冻结订单。候选缺当日报价时沿用明确跳过并记录原因；持仓缺价或关键风险输入未知时更严格地停止。不能把缺价判断改写成“已确认停牌”。

### 4. 跨进程命令行闭环演练通过

`scripts/demo_shadow_lifecycle.py` 用历史数据构造测试夹具，分别启动CLI进程：

1. 导入2026-09-01账户快照并两次生成计划，编号及文件内容不变。
2. 以模拟盘前资料核对700股桂冠电力卖单。
3. 将同一历史成交拆成300股、400股两笔；各重复导入一次，账本仍只计700股。
4. 导入2026-09-02的历史账户快照，现金和股数核对通过。
5. 只有这时才生成次日农业银行2,800股的补位计划，与原账户一致。

这是历史夹具演练，不是真实券商成交，不是今天的建议持仓。示例订单停留在独立影子数据库内。取消及拒绝分支另由对抗测试覆盖。

## 仍然需要完成的上线条件

- **真实来源接入**：当前需要导入规范化JSON/Parquet；尚未接通券商实时查询、自动日线更新与年度模型发布。输入中的来源和完整性回执仍需要真实供应链支持。
- **真实前向运行**：尚无未观察市场上的计划—委托—成交差异记录。至少三个完整复核周期可用于运行验收，不能据此直接认证长期盈利。
- **特殊事件处理**：乱序、晚到更正、额外手工交易和复杂公司行动仍需核对；公司行动若改变待执行非零风险目标，本版停止而不自动猜换算。
- **策略风险**：银行集中、日期敏感性、共同下跌和未形成主动全空仓能力，没有因本轮工程改造而消失。需另做匹配暴露对照及防守压力检验。

使用方法、字段要求与限制见 [每日计划与账户对账操作指南](SHADOW_EXECUTION_GUIDE_20260914.md)。建议先固定这套研究策略进行可记录的影子运行，工程验收与策略准入分别推进。
