# 按历史可见信息回放：研究约定

本约定于本轮运行前写定。替代随机冻结模型筛选历史事件的研究口径，不修改实时生产配置。

1. 年初训练模型，全年使用该模型；年度内层调参仅用该年以前已成熟的标签。训练和验证的标签结束日均须早于各自起点前20个交易日的截止日。规则数4/8、学习率0.003/0.01、早停轮数仅在过去内层时间验证集上决定。缺少训练/验证样本的年份跳过，不借未来补齐。
2. 缺失填充、缩放、聚类中心、模型权重和50%保留阈值均只由历史训练集估计；同一天的全部事件属于同一时间侧。年度决策只接收当年特征白名单，不接收当年标签。预测先落盘，之后才评估。
3. 20日板块标签从当前冻结数据重新计算；整个标签路径必须有效、同一指数连续段。保留标签结束日和每个模型的训练/验证ID、截止日、参数、权重及哈希。
4. 检查截断未来行情后事件识别与特征不变；测试未来标签篡改不影响历史训练样本和预测、同日事件不可分到训练与验证两边、名称公告日期不可穿越。
5. 个股只在板块模型通过且原事件当日仍确认时筛选；最多观察首次确认日起5个交易日。使用当日行业成员、历史存续和名称，名称公告须严格早于决策日。当天已生效但公告尚不可知的名称拒绝，未知拒绝。收盘决策，最早次日开盘观察。
6. 固定八种个股方案：原规则、取消前期放量、仅价格形态加趋势、仅趋势、仅价格形态、全部合格成员、价格加趋势后60日强度前5、价格加趋势后20日低波前5。全部披露，不从全样本挑赢家部署。各方案每个板块事件仅用首个出现候选的日期；以该日全部合格成员为配对基准。
7. 对3/10/20日次日开盘价格路径作描述：事件等权、年度分布、同日同板块相对值及时间簇重采样；缺路径单列，不悄悄删掉候选或补价。固定费用压力测试仅为价格观察，不是实际账户收益。官方涨跌停资料不足的交易不得称已确认可执行。
8. 限制必须保留：当前存量数据不包含历史供应商逐日版本，行业区间无公告时间；后复权序列和历史名称也可能被修订。因此此轮只能证明算法信息边界，不能认证当年收到的数据版本。策略家族、候选参数网格、个股门槛在今天制定/继承，历史开发偏差不能靠时间切分抹去。真实前瞻验证只能从版本冻结后开始。

后续不得把随机冻结模型产生的历史买点作为当时可以买的证据；原历史报告保留作审计，新的主结论引用本轮结果和上述限制。
