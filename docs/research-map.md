# 研究全景

以下按问题归类，避免把同一机制在不同版本中的重复实现当作独立成果。代码归档以近期核心模块为主，早期方向保留开发记录，不代表全部实现均在本仓库。

| 方向 | 研究问题与方法 | 沉淀 |
|---|---|---|
| 数据工程 | 多源行情、复权、金额与股数单位、历史退市与行业成员、缺日与空表 | 统一查询、质量检查、冻结快照及来源追踪 |
| 截面因子 | 低换手、低波、振幅、估值、反转、动量、非流动性、资金流 | 因子计算、Rank IC、分层分析、中性化与匹配对照 |
| 自动挖掘 | 遗传规划、表达式膨胀、冗余去除、CPU/GPU 计算一致性 | 表达式引擎、搜索与实验台账 |
| 预测与排序 | 线性模型、树模型、MLP/CNN、HMM、多期限标签、收益与风险双预测 | 滚动训练、成熟标签掩码、模型与基线比较 |
| 直接策略学习 | 早期 PPO/BiLSTM；后续基线初始化的神经策略与演化搜索 | 账户反馈接口、策略参数化、训练预算与重训周期研究 |
| 行业轮动与择时 | 板块相对动量、行业联动、广度、市场状态、龙头与篮子表达 | 分层选股与机制消融；检查板块观点如何经过个股执行 |
| 板块事件 | 内部相关性、上涨一致性、先涨后落、减速确认与多尺度去重 | 历史成员代理指数、事件识别与分布比较 |
| 模糊网络 | 固定模糊规则、岭回归、可训练 Takagi–Sugeno 网络 | 训练期预处理、早停、多种子与留出评估 |
| 跨市场传导 | 美股与行业 ETF → A 股；长假累积、多周期与状态条件 | 日历对齐；隔夜跳空与开盘后可交易收益的区分 |
| 持仓与现金政策 | 调仓频率、排名缓冲、持有确认、退出、风险预算、减仓与恢复 | 路径归因、小资金整手约束、日期敏感性与成本核算 |
| 日内与 IPO | 有底仓做 T、VWAP 偏离、反向做 T、新股阶段适配 | 分钟路径回放、仓位状态机与 T+1 处理 |
| 可转债 | 低价、双低及增强规则，退市与违约债覆盖 | 资产生命周期与数据缺失对回测解释的影响 |
| 审计与执行工程 | 前视、泄露、隐含杠杆、日内路径、公司行动、实际成交回报 | 独立账本核验、前缀检查、恢复状态与人工执行流程 |

## 贯穿各方向的问题

1. 信息在决策时是否已经可得，标签是否已经完整成熟？
2. 信号的解释力来自个股选择、风格暴露、市场状态还是不现实的成交假设？
3. 去掉复杂模型后，简单规则、随机选股或风格匹配对照是否表现相近？
4. 交易成本、现金、整手、停牌及涨跌停约束是否改变结论？
5. 新实验是否继续复用已经看过的历史，参数和模型分支选择是否完整记录？

## 当前记录方式

对失败、无增量和证据不足的方向同样保留说明。工程测试通过表示实现满足所检查的条件；统计差异、可交易净收益和真正未见数据的泛化能力分别评价。
