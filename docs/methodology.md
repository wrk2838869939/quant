# 研究方法与已知边界

## 时间与标签

收盘价、当日成交量及日终资金流只能在实际可得后使用。模型拟合需要检查标签结束日，避免前向收益跨入验证或决策时期。滚动训练本身无法消除先前因子发现和模型选型中已经使用的信息。

历史 `labels.py` 用每只股票后续 h 条观测计算收盘收益，不主动补齐交易日历，不处理退市清算。其标签可用于描述性研究，但不能直接代表收盘信号在同日成交的收益。完整停牌处理、标签成熟与成交口径应由具体实验另行定义。

## 模型与对照

复杂模型与简单因子、固定规则、随机选股及风格匹配对照分别比较。拆分信号层、过滤层、持仓层和执行层，不把整个组合的表现直接归因于模型预测。

实验台账的事件行数不等于独立策略尝试次数。DSR 的独立试验数、收益频率和分布假设需要显式给出；前提不足时应记录无法评估。

## 真实账户过程

现金、可卖股数、费用、整手、涨跌停、停牌与公司行动共同决定实际成交。复权价用于连续信号并不意味着账户可以直接按复权价记账。成交与事件流水独立重放用于检查现金和股数。

日线只有高低点，没有价格先后顺序。用日线推断盘中止盈止损必须声明路径假设；不能将有利顺序默认为事实。

## 数据与历史行业

原环境数据含退市股票，但这不自动消除所有幸存者或选样偏差。主档修订、全期质量筛选、行业归属覆盖和财务字段版本都可能影响结果。

成员进出区间可用于按日期构建板块，但不等同于完整历史发布时间认证。板块代理指数的个股极值外边界也不是实际可交易的板块盘中高低点。

## 板块事件与随机留出

事件筛选的收盘至未来收盘统计，不包含完整的入场可成交性、成本和资金曲线。随机留出允许不同时期混合训练，也可能使同日或重叠窗口跨集合出现，不能称为时间样本外验证。

Bootstrap 行情簇区间描述特定样本下的不确定性，不能自动涵盖重新训练、规则选择和多重比较。已经反复观察过的历史不会因重新切分而恢复为全新数据。

## 结果记录原则

工程正确性、统计证据、扣费后经济性和未来泛化是不同问题。保留失败和证据不足的分支；不把有限参数搜索失败扩展为对整个方法类别的否定，也不使用已被撤回的高收益数字作为结论。
