# cb_rotator — 可转债多因子轮动策略

## 定位

告别自研股票统计因子（详见 audit/28 的完整负面清单），转向 **A 股最成熟的公开策略族：可转债轮动**。
方法论：复现公开成熟逻辑（双低轮动）→ 因子增强 → 风控增强 → 多年 walk-forward 验证 → QMT 实盘。

## 为什么是可转债

- **T+0、无印花税**：执行成本 A 股最低
- **债底保护**：到期还本付息，下跌空间有限（对比：股票策略 MDD 动辄 -18%）
- **散户容量充足**：全市场 ~500 只在市，日成交额百万级即可无冲击交易
- **公开证据充分**：双低策略 2013-2023 十年年化 15.8%（集思录社区大量实盘）；西南证券转债量化月报确认动量/波动率/换手因子持续有效
- **与股票策略低相关**：转债涨跌 = 正股弹性 + 债底 + 期权时间价值

## 关键口径

- 双低 = 转债价格 + 转股溢价率；转股溢价率 = 转债价/(100/转股价×正股价) - 1
- 排除: 已公告强赎、剩余规模<3000万(流动性)、双高(高价高溢价=股性债博弈)、上市<10日(波动)
- 换仓: 周频(周五收盘) 为主, 与集思录主流一致

## 验证纪律 (继承 audit/28 教训)

1. 任何因子先在 IS(2018-2022) 发现, OOS(2023-2026) 验证
2. 单窗口 t 值再高也不算数, 必须多年度正比例 ≥70%
3. 成本口径: 转债佣金万0.5~2 + 冲击成本(尾盘竞价)
4. 默认怀疑: 公开策略的回测通常高估 (未来函数/幸存者/容量), 复现时逐项排查

## ⚠️ 2026-09-01 首轮验证结论 (暂缓实盘)

| 策略 | IS (2018-2022) | OOS (2023-2026) |
|---|---|---|
| 经典双低轮动 top10 | -0.0% (5年) | +0.8% |
| 低价轮动 top10 ≤130 | +1.0% | +0.5% (MDD 26.5%) |

均无超额 (vs 全转债等权)。与公开宣传 (年化15.8%) 的差异归因: ①打新收益消失 ②公开回测幸存者偏差 (我们含全部退市违约债: 搜特/蓝盾/岭南) ③下修史缺失致历史溢价不可精确还原 (数据硬限制) ④策略拥挤。

**数据资产保留**: data/ 下 1163 转债全生命周期 + 1021 正股 2018 起日线, 后续若拿到下修史/多因子数据可重启。

**结论**: 转债经典策略在诚实口径下同样不灵。+12.5%/8月的主板排雷策略仍是当前最优。
