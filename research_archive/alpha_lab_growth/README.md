## 本项目要回答的问题 (用户原始需求)

> 复用已有数据, 从第一性原理重构: 用美股隔夜信息+历史状态推断次日 A股板块轮动,
> 再用资金流入/价格历史分位/换手率变化选出中短期待涨股票, 开盘买入并持仓一段时间的策略。

## 一句话结论 (2026-09-18, 诚实口径, 可复现)

**原需求的美股→板块轮动部分被系统性证伪**: A股集合竞价几乎完全吸收美股隔夜信息
(指数 gap t=11, 板块 gap t=5~13), 开盘买入者在任何时间窗口(1/5/20/60日)、任何状态条件、
长假累积情形下都**不存在**可交易的轮动残余 (全部预注册判据未通过)。
个股层: 资金流/价格分位在可交易口径下**无正向选股 alpha** (资金流因子在错误标签下
曾显示 IC+0.118/t=5.4, 修正时序后 +0.02/t=1.1 死亡); 唯一稳健存活的结构是
**高换手股系统性跑输** (11/11 年)。
组合终局: 存活因子组合 V2 的**毛技能 ≈ +8.7pp/年** (随机分位 p98.5),
但"开盘买入+日级持仓"的执行成本 12-19pp/年 > 技能上限 → **指定执行方式下净值为负**
(V2 净 −7.3%/年; 滑点×3 压力 −20.5%)。破局只能靠结构变化(对冲/降频/并入实盘体系做过滤器), 非参数调优。

## 纪律 (本项目宪法)

1. **所有 md 结论不可信**, 包括本 README —— 用 `scripts/usx_*.py` + 当前数据复现后再信。
2. **预注册先于实验**: 判据写死在实验前 (USX_DESIGN §五 / USX_P0_2B_PREREG), 事后只能"通过/不通过"。
3. **开盘买入者口径**: 一切策略收益 open→open; close 口径的"解释力"默认视为吸收前幻觉。
4. **时序契约单一入口**: 美股→A股对齐只走 `alignment.py`, 新代码不得自建日期映射。
5. **同约束随机零假设**: 任何"策略有效"声明必须对比同宇宙/同执行/同成本/同持有的随机组合分位。
6. 数据理想但机制不通 → 按泄露/异常处理 (P0.3 mf_5d 教训: 错误标签下 IC +0.118/t=5.4/十年为正,
   修正时序后 +0.02/t=1.1 死亡 —— 这是本项目最重要的单条教训)。
