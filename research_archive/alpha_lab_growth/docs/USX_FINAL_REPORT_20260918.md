## 2. 三个层面的裁决 (预注册判据)

### 2.1 美股隔夜 → 指数: 信息真实, 吸收彻底 [已验证]
SPX 隔夜 → HS300 gap: corr 0.43 (t=11.4, 11/12 年稳定); → 日内: **负** (t=−2.6, fade);
→ **开盘买入者 5 日: t=0.5 ≈ 0**。close-to-close 口径 t=4.6 的"解释力"是开盘买入者拿不到的纸面收益。

### 2.2 美股隔夜 → 板块轮动: 不存在 [已验证, 主线判据拒绝]
- P0.2: us_1d/us_5d → 板块 oo3/oo5/oo5_rel (开盘买入者可得+相对口径): 19 板块仅 1 个 t>2 (57 检验, 噪声水平)。
- P0.2b (用户方向的历史动态扩展, 五假设): 多周期{1,5,20,60}(FM-t=1.3, 两段反号, 去top2归零)、
  趋势态条件吸收(up 1.7 / down 1.9 无差异)、长假累积(−0.2; 且假日累积美股→节后 **负** −2.2)、
  SPX20d 门(0.36)、确认/冲突交互(0.9) — **全部未达 |t|>3 主判据**。
- 机制解释: 集合竞价的功能就是吸收隔夜信息; "轮动扩散"假说在 A股 10 年数据中不成立。

### 2.3 个股层: 正向选股无 alpha, 规避高换手有 [已验证]
可交易口径 (因子∈close(D-1) → 买入∈open(D), 标签 open(D)→open(D+5) 减市场):
- mf_5d 资金流: IC +0.022 (t=1.1) **死**。⚠️ 标签时序错误版本曾显示 +0.118/t=5.4/十年为正 —
  全部为当日日内机械延续的泄漏假象。**本项目最重要单条教训。**
- pos_250d 52周高点近度: −0.002 **死**。
- turn_lv 换手水平: −0.079 (t=−3.6, **11/11 年负**) 存活(规避型)。
- turn_chg 换手变化: −0.050 (t=−2.1, 10/11 年负) 存活(规避型)。

## 3. 组合终局: 技能存在, 但买不起执行力

200 种子同约束随机 (9仓/h=5/全成本): 净 CAGR 中位 **−16.0%** (p95 −10.0%)。
成本拖累实测 ≈ 0.175%/边 × 日换手 36% ≈ **12-19pp/年**。

| 变体 | 构成 | 净 CAGR | 随机分位 | 毛 CAGR (零成本) |
|---|---|---|---|---|
| V1 原需求全合成 | mf+pos−turn+板块+门 | −21.1% | **p8 (毒药)** | — |
| **V2 去资金流** | pos−turn+板块top6+门 | **−7.3%** | **p98.5** | **+5.1%** |
| V2 @h=10 | 同上 | −5.0% | — | +1.2% (alpha 衰减快于成本下降) |
| V3 纯规避 | −turn−turnchg | −13.7% | p74 | −0.8% (无 gross alpha) |

- V2 毛收益 +5.1%/年 vs 随机毛 ≈ −3.6%/年 (净中位−16% + 拖累12.4pp) → **≈ +8.7pp/年 真实毛技能**,
  构成 = 换手规避 + 52周锚定 + 板块自身动量过滤 + 风控门, 与资金流无关。
- 但信号半衰期(≈几天, P0.3 IC 周频口径) ≪ 成本回收周期 → 预注册 h∈{3,5,10} 内不存在净值为正的组合。
- **这是结构性结论**: "开盘买入+日级决策+多股持仓+全成本"的执行方式, 在 A股该宇宙上的成本
  (12-19pp/年) 系统性超过该宇宙可得毛技能 (个位数 pp/年)。

## 4. 对用户原始需求的逐条回答

| 需求 | 裁决 |
|---|---|
| 美股(含历史动态) → 推断次日板块轮动 | **机制被证伪** (§2.1/2.2)。美股数据合法用途=风控门+执行层 fade 过滤 |
| 资金流入选股 | 可交易口径无 alpha (泄漏假象纠正后)。**反向信息**: 大资金流入后短期跑输 |
| 价格历史分位选股 | 无 alpha (52周锚定在本宇宙/本周期不产生可交易收益) |
| 换手率变化选股 | 有 alpha 但方向是**规避**: 高换手/换手突增的股票系统性跑输 (11/11 年) |
| 开盘买入持仓数日 | 执行成本 12-19pp/年 > 毛技能上限(个位数 pp) → **该执行方式注定净负** |

## 5. 遗产与可复用路径 (下一步的诚实选项)

1. **V2 的 +8.7pp 毛技能需要低成本变现方式**, 参数调优无解, 结构选项:
   - 对冲/多空实现 (规避高换手的空头腿是主要 alpha 来源, long-only 只能拿到残缺的一半);
   - 更低频的重定价 (周/月频调仓但持仓逻辑不变 — 需另做泄露审计, 未验证);
   - 用于已有实盘体系 (如 a_share_v18) 的**过滤器/门**, 而非独立策略。
2. **框架资产**: 时序契约/逐笔引擎/零假设仪器/PIT数据层可直接复用于任何后续想法。
3. **方法论资产**: P0.3 标签时序教训 (因子完成时点必须严格早于成交时点) 应写入所有后续实验的检查单。

## 6. 主要不确定性 (诚实声明)

- 毛技能 +8.7pp 的点估计含预注册外的事后成分 (V2 的构成是 P0.3 裁决后选择的存活因子组合);
  其相对零假设 p98.5 是干净的, 但"构成选择"引入了轻微选择偏差, 实际技能应打折。
- 成本模型 (滑点 0.1%/边) 对小市值段可能偏乐观; 滑点×3 压力下 V2 净 CAGR ≈ −20%。
- 回测窗 2017-2026 单一市场; mf/turn 因子在 2025-26 有衰减迹象 (拥挤), 外推需谨慎。
