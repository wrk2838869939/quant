# USX 架构设计与预注册 (2026-09-18)

> 原则: 第一性原理优先于数据表现。任何"数据理想但机制不通"的信号一律视为泄露/异常, 不入库。
> 本文档先于 P0 实验写定, 判据不可回改。实验结果另立文档, 只能"通过/不通过", 不能改判据。

## 一、策略主线 (用户需求的第一性重述)

**隔夜全球信息(美股) → A股板块层轮动推断 → 板块内个股(资金流/价格分位/换手)选择 → 开盘买入 → 持有 h 日开盘卖出。**

为什么这条链在第一性上可能成立(机制假设, 均待证):
1. **信息到达有时差**: 美股对全球行业信息的定价, 扩散到 A股对应行业需要时间 (Hong-Torous-Valkanov 行业领先市场; Monteiro 2023 美股行业→他国同行业日频领先; ADR 在母国休市时段承担价格发现)。
2. **轮动 ≠ gap**: 开盘竞价只吸收"快钱"部分; 机构调仓/主题扩散是数日过程 => T+1~T+5 的板块相对收益可能仍有残余趋势 (这就是开盘买入者能赚的部分)。
3. **个股层信息更慢**: 小市值/低关注股票对板块信息反应更慢 (lead-lag 文献), 板块内选"资金先行流入+价格结构健康"的股票捕捉扩散尾。

诚实的对立假设 (H4, 见调研文档): 若上述吸收都发生在开盘价里, 策略不成立, 降级为风控门。**不预设成立, 用 P0 裁决。**

## 二、因果时序契约 (硬约束, 全代码共享, 违反即泄露)

```
对 A股交易日 D:
  US_FEATURES(D)  := 全部美股 session U 满足 U ≤ D-1 (美东日历日), 取最近 K 个 session
  CN_FEATURES(D)  := 面板行 trade_date ≤ D-1 + PIT(行业成分/ST/上市日 ≤ D-1)
  执行(D)         := open(D) 买入; open(D+h) 卖出 (T+1 合规, h≥1)
  收益            := hfq_open(D+h)/hfq_open(D) - 1, 含成本
  不可成交        := 买入日 open(D) ≥ 涨停价 → 放弃; 卖出日 open(D+h) ≤ 跌停价 → 顺延至下一可卖开盘
```
- 涨跌停价: 用 pre_close × (1±10%/20%创业板科创板2014-08后/30%北交所不涉及) 四舍五入到 0.01 元判断。主板/创业板/科创板差异实现于 ST/板块规则。
- 时间戳审计: P0 实验前先抽查 10 个样本日, 确认 AKShare 新浪美股 date=美东日历日、Tushare index_global trade_date=美东日历日, 与北京时间的换算符合上表 (含夏令时切换周)。

## 四、信号定义 (预注册, 方向来自调研文档 §2.4, 双向存疑者标注)

### 4.1 板块层 (对每个 SW L1 i, 每日 D)
- `us_1d_i` = 锚 ETF 最近 1 个美股 session 收益; `us_5d_i` = 最近 5 个 session 累计收益 (各自横截面 z-score 于 11 ETF)
- `cn_mom_i` = A股板块等权收益 (D-5 → D-1, hfq), 板块自体动量
- `cn_breadth_i` = D-1 板块内上涨家数占比
- 板块综合分 (主线版): `S_i = z(us_1d_i) + z(us_5d_i) + z(cn_mom_i)`; 消融版各拆单项
- 全局门 (风控, 非收益信号): ASHR 隔夜 ≤ −3% 或 SPX ≤ −2.5% → D 日只减不加 (预注册)

### 4.2 个股层 (板块 i 内, 数据全部 ≤ D-1)
- `mf_5d` = (Σ5d(buy_lg+buy_elg−sell_lg−sell_elg)_amount_yuan) / circ_mv_yuan, 板块内 z-score; 方向 + (资金先行)
- `pos_250d` = close / max(close, 250d) ∈ (0,1], 52周高点近度; 方向 + (锚定动量); 二次项(过热)留稳健性
- `turn_level` = turn_5d 均值; 方向 − (换手负效应)
- `turn_chg` = turn_5d/turn_60d − 1; **方向双向预注册** (attention 启动 vs 博彩过热, 数据定)
- 过滤器: 上市 ≥120 交易日; 非 ST; circ_mv 分位 [30%, 95%]; 20日均成交额 ≥ 5000万(2014) 按通胀调整? → 不调, 用横截面分位 [20%, 100%]; D 开盘非涨停; 卖出日非跌停开盘

### 4.3 组合
- D 日: 取板块分 top K=3 的板块 × 每板块个股分 top M=3 → ≤9 只, 等权; 已持仓的保留至 h 日到期 (重叠账本, 每笔独立记账)
- 持有 h ∈ {3, 5, 10} (预注册网格, 主报告 h=5)
- 成本: 佣金 0.025%×2 + 印花税 0.05%(卖出) + 滑点 0.1%×2 (开盘竞价市价单的现实摩擦); 压力版滑点 0.3%×2

## 五、P0 预注册 (全部用 open 口径, 2017-01~2026-08 主窗, 2014-2016 备用)

**P0.1 指数层吸收测试**: X = SPX 最近1 session 收益(对齐契约); Y ∈ {HS300 gap(D), HS300 日内 open→close(D), HS300 close→close(D), HS300 open(D)→open(D+5)}。判据: 若 Y=close→close 与 open→open 的 R² 差异 < 1pp 且 gap 吸收了绝大部分 → H4 权重上调; 全年分段报告。
**P0.2 板块层传导测试**: 对每个映射板块: X = us_1d/us_5d; Y ∈ {板块 gap, 板块日内, 板块 close→close(D), 板块 open(D)→open(D+h) 减全市场中位, h∈{1,3,5}}。NW-t, 按年符号一致性。**通过判据(主线存活条件)**: 至少 6/10 个映射板块在 h∈{3,5} 的 X→Y 残余(去 gap 后)斜率 t>2 且 ≥7/10 年同号; 否则主线降级 H4。
**P0.3 个股层因子测试**: 全域(过滤后)每月末+每周三, 因子 {mf_5d, pos_250d, turn_level, turn_chg} vs open(D)→open(D+5) excess(减全市场等权) 的 rankIC 与 D10−D1 价差(多头只看 D10 与 D8-D10), 板块中性。通过判据: |IC| 方向一致、多头分位无"毒尾"(D10 年化 > −10%)、两段子样本(17-21 / 22-26)同号。

**泄露审计清单 (随每个 P0 报告输出)**: [ ]时区对齐抽查 [ ]特征只用≤D-1 [ ]标签/执行只用≥D [ ]PIT成分 [ ]含退市股 [ ]涨跌停不可成交 [ ]无未来窗口聚合 [ ]单位 *_yuan。

## 六、终评门槛 (组合回测, 预注册)
1. 主指标: 净 CAGR(open口径, 全成本) 的随机零假设分位 ≥ p95 (1000 次同规模随机组合, 同持有期同成本)。
2. 年度: ≥7/10 正; 单一年度贡献 ≤50% 总利润。
3. 子样本: 剔除 2024-09~2025-03 (政策脉冲窗) 仍为正。
4. 压力: 滑点×3; 剔除利润 top-10 个股后仍为正。
5. 消融: 去美股信号 / 去个股因子 / 去全局门, 主线必须显著优于每个消融版, 否则该组件以更简版替代。
6. 全部通过 → 才允许进入模拟盘设计; 任何一项不过 → 诚实报告"不成立"及其边界条件。
