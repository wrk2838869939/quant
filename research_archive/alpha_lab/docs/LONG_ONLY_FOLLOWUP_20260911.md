# 纯多头目标与可投资股票池（2026-09-11）

## 研究边界

接续[首轮合成对照](PORTFOLIO_IMPROVEMENT_20260911.md)。首轮没有找到更好的风险收益组合，因此改用 TRAIN 的前50收益检验信号，并分别检查趋势过滤、初始现金储备和信号日预算筛选。每一阶段均先固定配置、登记台账，再读取该阶段的组合结果。全部2022–2023结果都是已使用的开发样本，不能当作新OOS。TEST没有参与收益计算或选型，访问记录例外见首轮报告。

## TRAIN 选择规则

`configs/long_only_followup.yaml` 固定规则：原十一因子的方向沿用TRAIN权重符号，股票池统一要求十一项完整；分别计算2014–2018、2019–2021前50的20日毛超额。两段均为正才入选，然后按全TRAIN均值选择一个信号。

诊断仍是收益标签近似，不是现金账本。入场次日无开盘价则按没有买入、现金收益0处理；到期无开盘价则以此前最后可用复权收盘估值；已经摘牌按0回收。新股和信号日ST先排除，不按未来报价是否存在替换候选。末端保留 `h+1+embargo` 隔离。

唯一通过上述门槛的是 `lit:amihud`：早段平均超额 **1.489%/20日**、晚段 **0.433%/20日**、合计 **1.085%/20日**。它衡量单位成交金额对应的价格变动，不能直接解释为可兑现、无容量限制的alpha。

## 第二轮真实账本

目录：`outputs/long_only_followup/20260911T141208_459585Z/`。

| 方案 | 年化 | 每日最大回撤 | Sharpe | 平均股票仓位 |
|---|---:|---:|---:|---:|
| 原方案 | 3.44% | -9.78% | 0.364 | 81.1% |
| 原方案＋200日趋势 | 0.66% | -4.18% | 0.184 | 16.1% |
| Amihud，同一股票池 | 8.56% | -11.69% | 0.744 | 55.2% |
| Amihud＋200日趋势 | 0.71% | -6.71% | 0.170 | 11.4% |

趋势规则为中证500收盘高于200日均线才允许持仓，只在原月度信号日判断；25次信号中仅5次开启。两个趋势版本都降低收益及Sharpe，本轮否决，不继续扫均线长度。

Amihud原股票池版本费用翻倍后年化 **7.23%**、回撤 **-11.92%**、Sharpe **0.644**。但2022年收益 **-0.81%**、2023年 **+18.67%**，收益改善并非两年均有。相对原方案的年化平均日收益差区块重采样区间约 **[-12.3,+21.2]个百分点**，跨零且基于已用样本。

持仓流通市值几何均值约 **11.3亿元**，约 **61%净利润来自科创板**；行业映射的持仓权重覆盖率约47%。这些事实限制了行业中性归因和向主板实盘的外推。

初始半资金储备于第二轮账本出结果前登记，配置哈希在 `cash_reserve_preregistered.json`；真实以10.5万元重新计算手数，再合并独立的10.5万元不计息现金，后续不重平衡为固定比例。它并不等同于把收益曲线缩小一半：最低手数/容量拒单由364次增至751次，实际股票仓位只有12.7%，费用翻倍后年化仅1.25%。

## 信号日可投资股票池

据上述拒单原因固定第三轮 `configs/investability_followup.yaml`：保持同一Amihud分数及top50，分别以全部资金、半数资金设定名义每席预算。只使用信号日收盘价、成交量、上市日期、当时ST历史及板块手数，预计最低买入成本按收盘价上浮5%并计入最低费用；不满足条件的股票先从排序池中排除。

这是新增的组合规则，不是放松翌日成交约束：信号日先定top50，第二天涨停、停牌或预算不足仍可拒单，不能再按次日行情找替代股票。已持仓股票若离开该股票池，下一次调仓也按原账本规则退出。名义预算按初始交易资金计算，不随回测利润重新优化；费用压力始终复用原信号。

`src/investable.py` 用连续数组计算宽表掩码；首次准备因碎片化DataFrame逐行回写耗时而中断，记录保存在 `outputs/investability_followup/20260911T141947_839959Z/`。向量化后仍用同一配置重跑，未改策略门槛。

## 复现

```bash
# 在alpha_lab目录执行；每次生成独立目录并登记研究尝试。
python scripts/prepare_long_only_followup.py
python scripts/check_portfolio_improvement.py --prepared outputs/long_only_followup/<run>
python scripts/run_investability_followup.py
python scripts/run_investability_followup.py --resume outputs/investability_followup/<run>
# 保留的离线研究候选，仅运行半资金版本及费用压力：
python scripts/run_investability_followup.py --config configs/monthly_research_candidate.yaml
python -m unittest discover -s tests -p 'test_*.py'
```

中断后只能复用冻结的信号、配置与源码；源码哈希不同应建立新回放目录。`check_cash_reserve.py` 对本次已有事前登记的第二轮目录可复现现金储备情景；输出已存在时拒绝覆盖。每组均保存日频账本、逐笔流水、事件、逐股利润、逐年指标和费用压力，独立核对现金及股数。

## 第三轮结果与保留方案

最终目录：`outputs/investability_followup/20260911T142805_295786Z/`。

| 方案 | 两年累计 | 年化 | 每日最大回撤 | Sharpe | 平均股票仓位 |
|---|---:|---:|---:|---:|---:|
| 原方案 | +6.95% | +3.44% | -9.78% | 0.364 | 81.1% |
| 预算筛选，全资金 | +25.74% | +12.24% | -24.17% | 0.674 | 90.9% |
| **预算筛选，初始半资金现金储备** | **+18.64%** | **+9.00%** | **-8.67%** | **0.944** | **45.9%** |
| 同上，全部费用翻倍 | +14.40% | +7.02% | -8.93% | 0.767 | 44.7% |

半资金方案2022年收益 **+3.71%**、2023年 **+14.39%**；费用翻倍后分别 **+2.01%/+12.14%**。名义每席预算2100元，信号日可投资池平均约2329只；原始池约3780只。实际执行仅4次涨停买入拒单，未出现手数/容量拒单；这不是把涨停单替换成交的结果。

全资金版本2022年回撤达到24.17%，本轮否决。保留半资金版本为离线研究候选，配置为 `configs/monthly_research_candidate.yaml`；它尚不是实时每日更新或下单入口。

候选板块平均占总资产：主板 **28.8%**、创业板 **13.6%**、科创板 **3.5%**，其余为现金及应收；净利润分别约 **20781/14783/3580元**。这是跨板块组合，不能标成纯主板策略。最大单股权重 **2.72%**，最大单股净利润2204元；两年总净利润39144元，不由单一股票主导。

相对原方案，年化平均日收益差约 **+5.09个百分点**，20日区块重采样描述区间 **[-7.60,+17.77]个百分点**，仍跨零。三项指标在开发窗口改善，不等于证明未来有效；本轮存在多次研究选型，尚需前向纸面记录和更完整的微小盘容量验证。未改动生产配置或实盘任务。

44项测试通过，包括分红单位错误拦截、差异化实际权益、固定现金与动态股票权重、信号日信息隔离、板块最小手数和预算。所有最终情景现金及股数独立对账通过，最大现金误差低于1e-6元，无缺失涨跌停价或长期缺报价事件；这仅是已实现检查的通过，不是完整实盘认证。
