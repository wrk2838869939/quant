# 按用户澄清重定研究目标：从基线初始化的完整策略学习

状态：独立逐日策略接口、基线编译器与完整参数演化训练已实现，首轮已完成。执行配置见 `../configs/baseline_initialized_policy_v1.yaml`，[预登记](BASELINE_INITIALIZED_POLICY_PREREG_20260920.md)及[首轮结果](BASELINE_INITIALIZED_POLICY_RESULTS_20260920.md)分别记录执行口径与证据。以下保留方向设计；此前监督增量结果不能替代本方案验证。

## 用户目标及前次偏差

目标是在固定数据、10万元资金和30%历史回撤验收约束下，以已有较好策略作为学习的初始位置，在更高维的策略空间中探索高净收益策略。基线提供起点；最终策略允许与初始策略明显不同。

此前做的是预测未来收益排名或排名差，再用历史账户表现选择模型和修正幅度。模型的直接训练目标仍然是预测误差；频率、持股数、资格和账户分配大多被固定。因此它没有充分覆盖“从较好初始策略出发学习完整策略”的要求。

## 正确的对象与目标

策略应为可训练映射 `a_t = policy_theta(observation_t)`。观察包括截至t收盘可得的因子/行情、市场状态，以及本账户真实现金、旧仓、可卖股数、持有天数等。策略提出动作，冻结执行规则在后续交易时点撮合，产生实际现金和持仓，再反馈给下一次决策。

账户目标可写为：在登记的训练窗口与账户约束下最大化扣费后账户收益，候选必须满足历史最大回撤不超过30%。模型参数直接按交易轨迹回报更新，不以逐股票未来排名误差替代最终目标。验证时仍需按时间顺序隔离训练、选择和后续评价，不给未来表现保底。

基线只确定 `theta_initial`：

- 原有打分与过滤、频率、持股数、持有/换出规则都要包含在可表达策略中。
- 初值与原基线的实际交易/账户等价需要验证，不能仅声称神经网络理论上能表示。
- 初始化完成后开放全部策略参数；原基线分支系数、规则开关和动作头均可改变或失活。
- 不永久加入“离基线越近越好”的惩罚，不限制只能做小幅排名修正，也不把零增量当作学习的唯一保护机制。
- 回报最优已见候选可以保留为搜索精英。这是训练中的候选保存，与要求最终策略接近基线不同。

## 策略空间

在现有数据可支持的范围内联合开放：

| 维度 | 策略可学习内容 | 环境固定内容 |
|---|---|---|
| 个股信号 | 多因子非线性表示、条件分支、排序与买入许可 | 数据单位、发布日期、当时可得性 |
| 股票范围 | 可交易股票中的偏好与研究性过滤 | 当时上市状态、真实交易限制 |
| 调仓 | 日至月频的决策时机、保持旧仓或更新 | 信号完成后才能成交 |
| 持仓 | 持股数、目标分配、现金比例 | 10万元起始资金、整手、禁止隐含杠杆 |
| 退出 | 持有、减持、退出与重新进入 | T+1、停牌、涨跌停、真实可卖数量 |
| 市场条件 | 在可观测状态下选择不同行为 | 不使用未来市场状态标签 |

最终策略可关闭原低换手偏好，也可形成新的条件选股和持仓逻辑。策略空间不能只等于几个固定基线的非负加权。

上述为目标空间，不表示现有接口已经支持全部维度。持股数是否继续沿用现有1–5只边界，在首版执行契约中显式登记，不将旧实现限制冒充资金条件必然推导的最优值。

## 框架核对结果与必要改造

`src/portfolio.py::run_backtest`目前接受预先生成的整段signals；`top_n_schedule`可改变持股数，但与`retail_forecasts`/`hold_allowed`组合存在明确互斥。`risk_allowed`也是预先生成的日程。现有入口不能完整实现读取本次真实账户路径后再输出下一动作的闭环策略。

需要增加独立版本的因果逐日策略接口，保持原基线引擎和归档不变：

1. 逐日先执行之前已提交的订单，按原规则处理公司行动、锁定股、现金和估值。
2. 收盘后构造当时可得的市场观察和真实账户观察，只交付历史前缀，不交付未来行情对象。
3. 策略输出下一可执行时点的选股、持有/退出、仓位意图；区分“今天不调仓”和“清仓”，不能用同一空分数表示。
4. 执行层处理整手、费用、价格限制、流动性和现金约束；拒单/部分成交后的真实状态进入下一观察。
5. 模型不接触未来收益、未来净值峰值、最终回撤等评价量。完整轨迹评价只由训练器在回放结束后计算。

基线初始化优先使用可验证的规则等价参数化或策略编译。若某些模块只能通过行为模仿近似初始化，必须单独报告交易与净值误差，不能用近似成功代替精确初值验证；行为模仿仅是初始化步骤，随后放开策略参数按回报学习。

## 首选训练路线

首轮采用基线初始化的神经策略加演化策略/黑箱策略优化，直接使用真实账户回报评价参数。选择依据是整手、排序、过滤、拒单等操作使现有真实回测目标不光滑且不可直接反向传播。演化策略可用于直接优化参数化策略的回报；这只是方法适配依据，不是金融有效性证据。[Salimans等，2017](https://arxiv.org/abs/1703.03864)

搜索必须同时考虑：

- 多条基线分别初始化，保留不同策略区域；加入同预算随机初始化对照，验证较好初始位置是否有实际帮助。
- 开放全部网络和动作参数；不能只更新最后一层、一个混合系数或少数规则阈值。
- 多尺度扰动和多个并行候选区域；允许从初始点走远，不能依赖性能随某参数单调变化。
- 根据实测回报更新搜索分布，保留优秀候选及不同区域，记录全部尝试和失败。不能把固定网格枚举重新命名为完整策略学习。
- 协方差/步长自适应方案可参考CMA-ES，但高维计算成本需以实际参数维度评估；尚未指定已实现算法或训练预算。[Hansen，教程](https://arxiv.org/abs/1604.00772)

PPO等交互式策略优化可作为后续对照；不能因为历史项目里某个PPO实现失败就否定整个路线，也不能为了使用PPO而先换成不真实的无成本连续仓位环境。

## 下一阶段的具体产物与验收

先完成逐日策略接口、基线编译器与回报优化训练器，再做正式实验。首个可运行版本需满足：

1. 四个初始参照（低换手、低波/振幅、估值、等权）在相同输入下复现原交易与账户，或对无法精确编译的模块明确说明并停止等价声称。
2. 修改训练参数可以改变原基线主分支、研究性过滤、调仓和仓位行为；存在并测试可显著偏离基线的策略，不只证明微小扰动可执行。
3. 对相同策略参数重复回放结果一致；观察接口经过未来扰动/历史截断检查，订单遵守原现金与交易约束。
4. 训练目标来自账户路径回报，梯度估计或搜索更新不使用未来收益排名监督标签作为替代目标。
5. 预先登记时间窗口、风险判据、评价预算、策略维度、随机种子、初始点和随机初始化对照。训练预算不足只能记为有限搜索结果，不能声称已探索高维全空间。
6. 留存初始策略、每代参数与回报、选择依据、持仓和交易轨迹，并检验学习过程中是否实质改变行为。

冻结93股的质量隔离偏差、基线事后筛选和已观察历史依然存在。较好的训练初值与更大策略空间都不保证找到更高未来收益；研究要分别验证初值质量、搜索能力与跨期有效性。
