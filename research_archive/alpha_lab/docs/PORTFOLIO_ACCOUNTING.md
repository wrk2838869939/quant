# 月频组合记账契约（2026-09-11）

## 范围

`src/portfolio.py` 取代旧版按调仓日估值的实现。它是离线研究回测器，尚非下单系统。
固定方案由 `configs/monthly_portfolio_audit.yaml` 定义：原月频十一因子、TRAIN 2014–2021 定 ICIR 权重、VALID 2022–2023 回放、20 个交易日调仓、top50、模拟初始资金 21 万元。
既有候选已参考过 VALID/TEST，因此此次 VALID 只是修复后诊断，不是全新样本外证据。

## 每日账本

- T 收盘信号只在下一交易日开盘执行；信号文件的行号不再二次取每 20 行。
- 买单按配置的板块最小数量与增量取整数股，手续费纳入可用现金；不借钱，不默认碎股交易。
- 股票、现金、待到账现金分红分别估值；每日净值必须等于三者之和。每一天都落盘，包括非调仓日及最后信号之后的持仓日。
- 最高净值从初始资金开始计算，第一笔手续费也计入回撤。Sharpe 用日收益乘 sqrt(244)，年化收益按实际每日观察数计算。
- 新买股次交易日才能卖；红股按上市日解锁。卖单因跌停或停牌失败时逐日重试；下一次调仓重新评估是否继续卖。未成交买单不自动跨日追买。
- 每次调仓只尝试信号 top50；不能买或预算不足时保留现金，不用事后筛出的更低排名股票补仓。
- 新股、ST、尚未开市的板块不买；持仓变 ST 时发起退出。持仓保留带按固定配置处理。
- 每笔买入还受前一信号日成交量的 1% 上限约束，不用成交当天的收盘成交量来决定事前下单股数。

## 分红、送转与退市

1. 在股权登记日收盘记录应享权益的股数。
2. 除权日计入待到账现金及红股；现金到账前不可拿去买股票，红股上市前不可卖。持仓卖出后，已确认现金应收款继续保留。
3. 使用真实分红送转记录，不把复权系数变化假装成股数增加。除权参考价与现金/送转金额不符时停止。
4. 原始前收参考价无解释跳变时停止，即使复权因子未变化也不能绕过。若原始参考价连续、只有复权元数据变化，则单独记录且不改变现金/股数。已核验配股按“不参与、不追加资金”处理，其他新配股和特殊重组仍须核对后才能继续。
5. 停牌用最后一次有效估值，不退回买入价。连续缺报价达到 20 个交易日产生估值待审标记。
6. 摘牌日在本次保守配置下减记为零，不假设能按最后报价成交，也不把“后面没有行情”当作提前知道退市。

差异化分红另以已核验的参与股本比例计算市场除权参考价，投资者现金和红股仍按实际每股权益入账。比例必须与公告、实施日期及分红金额对应，不能为了通过校验而改分红金额。恒林股份2022年事件见 `configs/corporate_action_components.yaml`。

本次现金分红统一扣减 20%，是固定保守情景，不是按真实持有期核算的税款；红股不足一股部分向下取整并记录。复杂公司行动、零股分配、税务和实际到账记录仍需券商层验证。

## 成交和费用的边界

优先使用 Tushare 的逐日涨跌停价，避免把历史创业板涨跌幅变化写成静态比例。缺少价格限制数据时拒绝该笔交易并标记报告，不擅自认定可以买卖。
处于开盘涨停时不买、开盘跌停时不卖；开盘成交仍是近似，不保证真实集合竞价能以此价格全额成交。
费用沿用固定买入 0.1%、卖出 0.2% 的综合摩擦情景，另设单笔最低费用 5 元；不声称逐项复现历史税费。
本轮没有买卖盘深度、逐笔排队、停牌公告时点、真实账户交易权限、实时滑点和委托回报。

## 独立检查与产物

从逐笔交易、现金分红到账和红股/退市事件重建现金及股数，与引擎的每日状态独立对账。
结果包含 `*_daily.csv`、`*_trades.csv`、`*_events.csv`、`*_holdings.csv`、汇总和源码哈希。
`execution_data_sufficient=false` 表示存在缺涨跌停价、长期缺报价或未解释复权变动，不能把该结果当作完成执行数据验收。
即使该字段为 true，也仅代表这些检查通过，不代表可以实盘或确认收益有效。

旧实现归档于 `legacy/backtest_weekly_v3.py`，仅可导入作错误口径对照；旧 CLI `scripts/backtest_weekly.py` 已转到新审计入口，要求显式提供固定信号目录。

```bash
python scripts/prepare_monthly_audit.py
# 如下载中断，复用同一目录而非重新选参数：
python scripts/prepare_monthly_audit.py --resume outputs/monthly_portfolio_audit/<run>
python scripts/audit_monthly_portfolio.py --prepared outputs/monthly_portfolio_audit/<run>
```

## 规则与字段依据

- [上交所主板交易机制](https://english.sse.com.cn/start/trading/mechanism/)：买入数量规则。
- [上交所科创板投资者教育](https://edu.sse.com.cn/tib/)：200 股最低数量及其增量。
- [深交所 2020-08-21 交易安排说明](https://www.szse.cn/aboutus/trends/news/t20200821_580924.html)：创业板历史交易机制变化和股数规则。
- [北交所 2021 年交易规则](https://www.bse.cn/uploads/6/file/public/202109/20210909101516_y5wn2y3ft9.pdf)：板块申报数量与最小价格变动单位。
- [Tushare 分红送股](https://tushare.pro/document/2?doc_id=103)：每股现金、每股送转、登记日、除权日、支付日及红股上市日。
- [Tushare 每日涨跌停价](https://tushare.pro/document/2?doc_id=183)：按历史日期获取价格上下限。

规则核对用于本次 2022–2023 历史窗口；上线前仍须按账户可交易范围核对当时规则。
