# 财务披露事件恢复与五股试点

日期：2026-09-13。**字段级版本时间线已跑通；原拟定的两项财务变化尚不能直接进入模型。** 五只原持仓的20份公告恢复98条事实，但10项跨年变化只有3项获得本次文档可比性检查支持。其余保留未知，未据此删除股票。没有训练模型、读取行情或收益标签，也没有改动生产。

本轮是[财务时点准入审计](FINANCIAL_PIT_GATE_20260913.md)的实际恢复试点。完整产物见本轮目录（原记录路径：`../outputs/financial_events/20260913T075514_058723Z/`）。

## 1. 修订成为独立事件，旧值不再被覆盖

事件逐字段记录公司、报告期、实际公开日、值、单位、合并范围、会计口径标识，以及原PDF、页码、数字和文件哈希。内容变化产生新事件ID；原版本继续保留。

康美对照用三份既有原公告恢复9条事件，回放24个日期—字段请求：

| 查询日 | 已知的2018经营现金流 | 已知的2018 EPS |
|---|---:|---:|
| 2019-04-30，初报公告当日 | 尚不使用 | 尚不使用 |
| 2019-05-01 | −31.9153亿元 | 0.184元 |
| 2020-06-18，更正公告当日 | −31.9153亿元 | 0.184元 |
| 2020-06-19 | +3.0562亿元 | 0.0302元 |

采用“公告日严格早于查询日”的保守规则，不假设公告当天的具体发布时间。更正公告中“调整前”比较列作为历史上下文保存，不再次覆盖调整后值；针对旧期新披露的调整后数字，则在新公告日期起成为可用修订。

原件：[2018年报](https://static.cninfo.com.cn/finalpage/2019-04-30/1206168292.PDF)、[2020年公开的后续年报](https://static.cninfo.com.cn/finalpage/2020-06-18/1207936073.PDF)。本例验证时间线机制；没有据此声称已收齐两次披露之间的全部更正。

## 2. 原五股的两项变化：数值可复算，不都具有同口径意义

固定2022-01-25原警报的五只持仓，恢复2020/2021半年报和三季报。数据来自原公告，未从现代财务快照复制真值。下表是**各年初报口径的描述性差值**：2021Q3指标减2020Q3指标，单位百分点。

| 股票 | 营收同比增速变化 | CFO/营收比变化 | 本次可比性判断 |
|---|---:|---:|---|
| 茂业商业600828 | +62.31 | −64.60 | 营收总额/净额切换；现金流跨新租赁准则，均不作为已认证经济变化 |
| 大秦铁路601006 | +0.89 | −11.41 | 收入准则、合并范围与租赁变化，未恢复统一比较口径 |
| 宁波港601018 | +43.94 | +70.04 | 收入确认变化、同控并购重述与租赁变化，未恢复统一比较口径 |
| 新华文轩601811 | +4.32 | −16.60 | 两项初报差分获得本次文档一致性支持 |
| 飞科电器603868 | +7.17 | −12.02 | 营收差分获得支持；现金流跨年分类可比性仍未知 |

例如茂业2020半年报第6页明确说明收入下降同时受净额核算与疫情影响。不能把两者混合后的同比变化全部解释为经营变化。飞科2021半年报第66页披露新租赁准则不调整比较期，相关租赁付款进入筹资现金流，因此CFO比率变化也不能未经衔接就当作经营现金创造能力变化。

“获得文档支持”仍不等于完整历史认证，也不等于有预测能力。五股来自此前实际持仓，不是随机样本，3/10不能外推为全市场通过率。具体原件、公式及会计页见大秦/宁波报告（原记录路径：`../outputs/financial_events/20260913T075514_058723Z/pilot_601006_601018/REPORT.md`）和其余三股报告（原记录路径：`../outputs/financial_events/20260913T075514_058723Z/pilot_600828_601811_603868/README.md`）。

## 3. 初报序列与决策日最新已知值分别保留

大秦、宁波的2021公告提供了10条针对2020报告期的新修订事实。它们保留2021实际公开日，并被统一事件账本在2022-01-25的查询中选中；原2020初报没有删除。

因此上表的“各年初报差分”不是2022年决策日最新已知、且已经统一会计口径的最终特征。将2020原值、2021调整后比较数和未调整的2019比较数随意拼接，会产生另一种口径混用。

统一账本共107条事件：五股98条，加康美对照9条。所有事实可追溯到原文；源文件数字与单位换算已复核。未完成跨报告口径衔接时，自动累计差分不能放行。当前所有事件集合仍标记`history_complete=False`，不会自动绕过上一轮训练门槛。

## 4. 已完成的工程与检验

- 新增`financial_events.py`：不可变追加、字段独立更新、同日公告排除、同日值/单位/口径冲突返回未知、明确缺失不回填。
- PDF校验检查哈希及指定页的原数字；行列语义和会计口径仍须对照原件审阅，不能只靠数字搜索认证。
- 季度累计差分仅允许已登记的CFO、营收流量，并检查公司、单位、合并范围、会计口径与同年相邻季度；资产余额等存量不能混用。
- 两组独立公告恢复共20份PDF、98条事实；原文值、单位、公式、比较栏和可用日期核验通过。统一组装再次核对全部98条出处、10条新修订选择和事件顺序不变性。
- 完整**263项测试通过**。独立审阅修复了整数/小数追加导致ID变化、空白出处数字绕过校验、存量误作季度流量三项问题，新增回归均通过。

数据和代码核验通过不代表股票选择或退出政策通过。本轮没有计算收益、回撤或Sharpe。

## 5. 扩展规模与研究决定

对原243,955个机会的当前报告期、上年同期及必要前一季度去重，得到**95,517个股票—报告期取证组合**。这是证据依赖规模，不是PDF数量或PDF数量下限：一份公告可能覆盖多个期间，修订搜索又可能需要更多文件。具体组合已输出为`assembled/stock_period_evidence_requirements.csv`。

本轮未启动全量抓取。当前困难包括事件完整性、可比范围和准则衔接；下载更多PDF本身不能认证这些经济语义。先保留已恢复事实及未知状态，不把会计重分类当成经营改善，不以缺少财务认证为由缩减可投资股票池。

下一步若继续财务增强，应在固定历史样本中先取得具有可比口径的披露信号，再与同覆盖价量对照比较。原先的两项财务跨年变化仍属未通过数据准入的研究候选，不能宣称已改善五股选择或主动空仓。
