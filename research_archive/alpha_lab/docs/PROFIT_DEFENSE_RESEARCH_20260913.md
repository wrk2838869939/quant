## 4. 退出更快、暂停补仓、整组退出：逐项证伪

本轮保持原月度入场和候选排名；周初收盘检查，只能向下一交易日提交订单。报警沿用长期两项均弱＋完整20日内至少10日弱；组合暂停以当前股票市值一半触发，冻结风险篮子和权重，月度复核时原篮子超过半数恢复原趋势才解除。阈值未优化，未知不能当恢复。

| 机制 | 2022起收益 / 回撤 | 2024起收益 / 回撤 |
|---|---:|---:|
| 原Hybrid | **147.42% / 15.97%** | **55.54% / 14.64%** |
| 周频提前退出 | 109.58% / 16.37% | 47.06% / 15.92% |
| 仅组合暂停补仓 | 141.97% / 15.10% | 55.54% / 14.64% |
| 周频退出＋暂停 | 109.58% / 16.37% | 47.06% / 15.92% |
| 周频退出＋触发后整组退出 | 109.58% / 16.37% | 47.06% / 15.92% |

周频退出增加成交：完整67→87笔，近期41→46笔；收益和最大回撤同时变差。2026年7月28日该版本卖出东方盛虹，之后20个交易日复权收盘涨12.82%；该股全路径损益从原策略+2,176元变为−618元。后续涨幅仅作退出代价描述，不能直接等同账户少赚金额。

**后三种周频账户相同有明确原因：**周频个股退出先移走报警股票，组合“半数同时报警”未触发；暂停和整组退出没有被真实激活。不能据此声称空仓无效，也不能把无差异当成稳健性证据。唯一真实暂停来自“保留月度退出＋仅暂停”完整账户：2023-10-30触发，2024-02-01恢复，少亏回撤但降低全期收益。所有账户均未出现初始化之后的完全空仓。

快跌与长时间下跌应分别评估，问题划分参考[AQR关于防守快慢的分析](https://www.aqr.com/insights/research/alternative-thinking/should-your-portfolio-protection-work-fast-or-slow)。其跨资产结论及参数不直接移植到本项目。

## 5. 当前判断与下一轮应验证的问题

1. **盈利：**近期银行行情可以用简单组合获得，现有主动调整尚未显示优势；较长窗口仍有明显非银行收益，保留低换手选股与长期持仓作为研究基线。
2. **防守：**独立检验持仓从高点的回吐、亏损扩散及当前风险暴露，避免把“半年前买入仍赚钱”当作“现在风险不大”。同时衡量正常回调误卖及恢复后的补位代价。
3. **实验纪律：**月度入场保持冻结，把提前退出、暂停补位和恢复分别消融；指标应包含报警前损失占比、误退出后20/60日路径、空仓时长和错失收益，不能只追求更小终值回撤。
4. **数据：**先补齐历史行业缺口，再做行业＋规模＋价值/股息的共同风格对照。不能使用当前行业回填后宣布完成PIT认证。

这些是下一轮待检验假设，不是已经有效的新规则。本轮未更换主策略、未晋升任何防守方案，也未进入实盘。
