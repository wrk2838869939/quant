# Walk-forward 逐年样本外重验 — 预注册 (2026-09-18)

> 动机: 低波合成因子(alpha_lab 月频主线)的诚实评估现状 —
> ① 旧 TEST (+15.3%) 记账错误已作废且 TEST 被代码闸冻结;
> ② 2026-09-11 风格归因 (VALID 2022-23, 最严对照 size_liquidity_matched) 超额仅 +2.3pp/年
>    (bootstrap 95% 区间 −2.4~+7.0, 不显著), 且其信号构造 (selection 规则至 2021 / 合成权重至 2023)
>    对 2022-23 评估窗存在样本内污染;
> ③ VALID 仅覆盖 2022-23 一种风格环境, 无法回答"该模型是否跨牛熊稳定"。
> 本实验不触碰 TEST (全部评估窗 ≤ 2023-12-31), 不改变任何生产配置, 目标 = 对模型技能的诚实重估。

## 方法 (预注册, 执行前写定)

对每个评估年 Y ∈ {2019, 2020, 2021, 2022, 2023}:
1. **滚动拟合**: 合成权重只用 trailing 窗 [Y-5-01-01, Y-1-12-31] 的 20 日间隔截面 RankIC
   (标签 hfq_close shift(-20) 超额截面秩, 边界 purge 20 交易日), ICIR 加权;
   因子集 = synth_weights_h20.csv 同款 11 条 (9 lit + 2 GP), 不增删不换。
2. **信号**: Y 年内每 20 交易日一个截面, 各因子截面 zscore × 权重逐元素求和
   (任一分量缺失 → 该股 NaN = 不合格), 与 synthesis_and_test 语义一致。
3. **资格**: investable_signals (价格预算×1.05 / 成交量参与 1% / ST / 上市龄≥60日 / 板块手数规则),
   capital = 21万 × active 0.5, top50 — 与 09-11 链一致。
4. **对照**: size_liquidity_matched (同板块+同行业, log_mv+log_amount20 百分位距离最小, 不放回),
   seed=20260918; 09-11 研究中最严格的对照。
5. **执行**: src/portfolio.run_backtest (限价/涨跌停拒绝/分红/配股/停牌), 买入 0.1% 卖出 0.2% + min_fee 5,
   active 半仓 + 等额现金储备 (add_cash_reserve); 年窗 = 自然年。
6. **数据**: dividend/stk_limit 按年窗抓取并缓存 (fetch_execution_data, 重跑续传)。

## 判据 (预注册)

- 主判据: 5 年合并日度超额 (candidate − control) 年化 > 0, 且 ≥3/5 个评估年超额为正。
- 次判据: 分年超额中位数 > 0。
- 不确定性: block bootstrap (20 日块, 2000 次) 95% 区间; 报告但不作为通过条件。
- 台账: 本协议记 1 次试验; 分年结果为同一预注册协议的分解, 不单独计试验、不事后挑选。

## 描述性附件 (不进入判据)

- 合成因子十分组 (年内, 等权持有 20 日, 无成本): 检验"规避结构"(Q1 垫底、Q2-Q10 平坦) 是否逐年成立。
- candidate 盈利的行业分布 (按首次买入日 PIT 行业): 银行集中度。

## 预注册的结论映射

- 若主判据通过且各年方向一致 → 模型技能为"跨环境稳健", 值得继续投入 (低频/风控增强方向)。
- 若超额集中于 1-2 年 (例如仅 2022-23) → 判定"风格阶段产物", 模型降级为观察态, 不再投入选股层。
- 若某年权重拟合失败 (trailing 截面不足) → 该年跳过并在报告中显式说明, 不得用其他窗口顶替。
