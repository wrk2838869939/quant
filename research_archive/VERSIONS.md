### 1. star_market_sell_model（v8 ~ v11）

| 项目 | 内容 |
|------|------|
| 路径 | `star_market_sell_model` |
| 方法 | PPO + BiLSTM 买卖一体化决策 |
| 状态 | **已废弃** |

**为什么废弃**：分钟级 OHLCV 信噪比极低，RL 策略必然坍缩为「全 Hold」或「全清仓」两种固定规则，未学到盘中择时能力。

**贡献**：明确了方向——放弃日内卖出择时，转向日频选股。

### 8. kcb_v16（单支日内做T · 2026-08-04）

| 项目 | 内容 |
|------|------|
| 路径 | `kcb_v16` |
| 版本 | 16.2.1 |
| 定位 | 科创板单支股票日内半仓T+0 + 满仓被套解套 |
| 状态 | **生产就绪** |

**核心理念：** 不选股，专注一支股票的日内做T降成本。规则驱动（非机器学习），每个信号有明确逻辑。

**架构：**

```
position_state.py  仓位状态机 (EMPTY/HALF_LONG/HALF_TRAPPED/FULL_TRAPPED)
    + T+1 合规追踪 (_sellable_shares / _locked_shares)
    + 隔夜仓 (overnight_short)

intraday_engine.py 日内做T引擎 v2
    方向判定 → 趋势过滤 → VWAP+动量+K线形态 → 止盈/止损/漂移检测
    5大优化方案: 智能尾盘 / 正T解禁 / 方向重构 / 信号质量 / 趋势过滤

trapped_handler.py 被套分级 L1/L2/L3 + 紧急清仓
risk_manager.py    止损/止盈/连续亏损限制
notifier.py        QQ邮箱通知 (交易/仓位/风控/日终)

live_monitor.py    实盘监控 (自动下载+信号+邮件+隔夜)
backtest.py        回测引擎 (场景模式 / 正常模式)
```
