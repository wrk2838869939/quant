# a_share_v18 — 两层轮动 诚实口径版

**基线**: a_share_v17（=v16.4 修复版）
**日期**: 2026-08-26
**定位**: 策略逻辑不变，只修口径。v17 及以前的回测收益（如 +1189%）含下述水分，v18 为诚实口径基准。

## 相对 v17 的四项修复

### 1. 训练标签泄露（回测）
v17 每日重训时，训练池最后 `hold_days`(5) 天的行，其 5 日前向标签用到了**决策日之后**的收盘价（实盘不可得）。
v18: 训练池剔除最后 5 个训练日期（`stock_selection.label_leak_fix: true` 可开关）。
影响大：LGBM 半衰期仅 3-4 日（audit/24），泄露相当于每天白送模型 ~4 天新鲜度。

### 2. 涨停不可买（回测 + 实盘）
v17 回测 316 笔中 27% 买入日收盘 ≥+9.9%（≈封板，收盘价实际买不进），这批笔均 +6.4% vs 其余 +3.0%。
v18: `stock_selection.limit_up_buy_filter: 0.098`，回测按买入日收盘涨幅、实盘按 现价/昨收 过滤，两边口径一致。

### 3. 现金约束组合记账（回测重写）
v17 每天按「总资金×regime仓位」开仓，不管前一天 T+2 持仓是否已卖出 → 隐含杠杆（14.8% 的交易日单日新买入超总资金），绝对收益虚高。
v18: 组合级现金/持仓逐日结算 —— 卖出回款才可用于新买入，敞口上限 = 总资金×regime仓位；日收益改为净值 MTM 口径；手续费双边（`buy_fee: 0.0002` / `sell_fee: 0.0008`）成交时扣除。
附带修复：v17 固定 TP/SL 分支**漏了盘中 hi≥tp 的止盈检查**（TP 只靠开盘跳空触发），且收盘确认止损在窗口扫描之后才回溯判定（顺序前视）。v18 按时间顺序逐日判定：开盘跳空 → 盘中止盈 → 收盘确认止损 → 到期收盘卖。

### 4. 实盘风险平价静默退化
v17 实盘 `atr14_ratio` 只在被 GBDT 选为当日 top-10 特征时才存在于预测表，否则全部按默认 0.05 → **静默退化为等权**。v18 始终从当日特征映射 atr14_ratio。

## 诚实口径回测结果（2026-01-05 ~ 08-24, 21万）

| 口径 | 累计 | MDD | Sharpe | 笔均 |
|---|---|---|---|---|
| v17 官方（旧） | +1189% | -7.2% | 10.74 | +3.87% |
| v18 保留标签泄露（消融） | +70.2% | -6.7% | 5.36 | +1.22% |
| v18 关涨停过滤（消融） | +27.2% | -10.8% | 2.03 | +0.30% |
| **v18 全修复（诚实）** | **-14.2%** | **-22.5%** | **-0.98** | **-0.29%** |

**结论**：v17 口径的 alpha 大头来自训练标签泄露（每天白送 ~4 天新鲜度，LGBM 半衰期仅 3-4 日）+ 涨停买入假设 + 隐含杠杆。全修复后策略本身接近不赚钱。
注：涨停过滤在回测按收盘价判定（偏保守），实盘 14:30 买时部分股票尚未封板，真实表现介于 -14% 与 +27% 之间。
