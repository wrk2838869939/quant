# 步骤 4 — IC 与 Rank IC 计算报告

**审计日期：** 2026-08-15
**方法：** 对每个特征逐日横截面计算与 `future_ret`（5 日前向收益，与训练标签 hold_days=5 一致）的相关系数：
- **IC** = 日截面 Pearson 相关均值
- **rank IC** = 日截面 Spearman 相关均值
- **ICIR** = IC均值/IC标准差（信号稳定性），**pos%** = IC>0 的交易日占比
- 已剔除市场级特征（同日唯一值 >50%，如 index_ret_5d/20d/vol_ratio，无截面方差）
**复现脚本：** `audit/scripts/ic_rank_ic.py`；结果 `audit/outputs/04_ic_kcb.csv`、`04_ic_ashare.csv`

## 三、核心发现 🔴

### 3.1 特征 IC 极度微弱，几乎没有选股能力

- **KCB 最强 |rank IC| 仅 0.063**（amount_ma20），其余全部 < 0.055。业界一般要求 **|rank IC| > 0.05 才算有信号**，> 0.1 算有效因子。KCB 的大多数特征处于「噪声」区间。
- **ICIR 全部 < 0.33**（KCB）/ < 1.03（A股）——信号方向极不稳定。ICIR > 0.5 通常才算可用，> 1.0 算优秀。除 A股的 amount_ma20 外全部不达标。
- 结论：**这套特征体系在两个市场的截面预测力都接近零**。

### 3.2 最强的信号是「负向流动性反转」，而策略完全不使用它

- 两市中 `amount_ma20`（成交额）都是最强负向信号（KCB rankIC −0.063、A股 −0.139）：**低成交额股票未来收益更高**（流动性/小市值反转效应）。
- 但步骤 3 显示策略对 `amount_ma20` 的暴露 ≈ **0**（+0.02 ~ +0.11）——策略**没有利用**这个唯一有效的因子。

### 3.3 策略重仓的「动量」因子，在 KCB 上是负预测力 🔴🔴

- 步骤 3 显示策略强烈偏好动量/趋势因子（ma20_dev、ma60_dev、ret_10d、ret_20d 暴露 +0.6~+1.3）。
- 但 KCB 全样本上这些因子的 rank IC **全部为负**（−0.035 ~ −0.050）：
  → **策略在系统性地买入「未来更可能下跌」的股票（相对截面而言）。**
- 在 A股，动量因子 rank IC ≈ 0（−0.005 ~ −0.035），也无正向预测力。

### 3.4 回测收益与因子 IC 严重背离 → 收益非来自选股

| 现象 | 数据 |
|------|------|
| 策略名义收益 | KCB +435% / A股 +181% |
| 策略所用因子的截面预测力 | \|rank IC\| < 0.07（几乎为零） |
| 策略重仓方向的预测力 | 动量为**负**（KCB） |

**逻辑推理**：既然选股模型的因子几乎没有（甚至反向）预测力，那么 +435%/+181% 的收益**不可能来自「选股 alpha」**，只能来自：
1. **regime 择时**（bear/panic 空仓，避开了 3 月急跌）；
2. **止盈止损 + 移动止盈规则**（把盈亏分布右偏化）；
3. **步骤 1 发现的未来函数/结算 bug**（放大名义收益）。

### 3.5 附注：三个 clu 特征的 rank IC 完全相同

- KCB 中 `cat_ret_5d_clu` / `cat_rank_5d_clu` / `cat_disp_20d_clu` 的 rank IC 均为 −0.0060。
- 其中 `cat_ret_5d_clu` 与 `cat_rank_5d_clu` 数学等价（排名与收益单调同构），`v14/selector.py` 的 IC 去重逻辑已识别此问题；`cat_disp_20d_clu` 相同纯属巧合但进一步说明该特征几乎无信息。

## 四、结论

**特征层面几乎没有可被模型捕获的截面 alpha**，而回测收益却极高 → 这构成「回测收益不可信」的又一条强证据，与步骤 1（未来函数）、步骤 2（Sharpe 6.5 不现实）相互印证。

> 后续若修复未来函数后收益大幅缩水，应属预期；若想保留真实 alpha，应**换用有正 rank IC 的特征**（如 amount_ma20 的低成交额反转），而非当前这套「动量 + 高波动」组合。
