# ipo_trader — 新股日内做T交易系统

针对A股新股（科创板688 / 创业板300）的**日内T+0做T程序**。通过上市阶段感知 + 参数自适应，在波动最大的上市初期用做T降成本，实现盈利和回撤控制。

## 设计理念

### 为什么新股适合做T

新股上市初期的3个特征，使其成为日内做T的黄金窗口：

1. **波动极大**：科创板前5日无涨跌幅限制，首日常见振幅 15-40%，是普通股票（日均振幅2-3%）的5-10倍
2. **换手率高**：首日换手率常超70%，流动性充裕，买卖价差小
3. **波动衰减可预测**：振幅随上市天数规律性衰减，参数可以渐进收紧

> 举例：宇树科技（688836）发行价 ¥150.80，人形机器人赛道。如果首日振幅30%，一次反T（先卖后买）在 ±¥45 的区间里做，盈利空间远超普通股票。

### 核心设计：上市阶段自适应

传统做T系统使用**固定参数**（比如 VWAP ±1.5σ、止盈 1.2%），这在老股上合理。但新股第1天的振幅可能是第20天的5倍，固定参数会导致：

- **上市早期**：VWAP 带太窄，频繁假突破，手续费吃掉利润
- **上市后期**：VWAP 带太宽，信号太少，错失稳定获利机会

**解决方案**：根据上市天数自动切换四套参数。

```
上市天数:   D0         D1────────D5        D6────────D20       D20+
           │          │                   │                   │
阶段:      首日       首周                早期                稳定期
           │          │                   │                   │
VWAP σ:   3.0        2.5                 2.0                 1.2
止盈:     4.0%       3.0%                2.0%                1.0%
止损:     2.0%       1.5%                1.0%                0.6%
仓位:     25%        40%                 50%                 50%
趋势过滤:  关闭       关闭                开启                开启
```

| 参数 | 为什么这样设计 |
|------|--------------|
| 首日 VWAP 3.0σ | 首日振幅 20-40%，2σ 会频繁触发假信号 |
| 首日仓位 25% | 首日不确定性最大，小仓位试探 |
| 首周趋势过滤关闭 | 前5天没有足够的"趋势"可言，纯波动驱动 |
| 止盈随天数收敛 | 首日4% ≈ ¥6（150.80 的4%），跟手续费比有意义；稳定期 1% 匹配衰减后的振幅 |
| D20+ 回归常态 | 20天后基本等同于老股，用接近 kcb_v16 的参数 |

## T+1 合规

A股T+1规则：**今天买入的股票今天不能卖出**。这对新股做T有直接影响：

### D0（上市首日）

```
09:30 买入底仓 → 当日不可卖出！
──────────────────────────────
系统行为: 自动跳过所有做T信号
风控: 仍然监控止盈/止损/紧急清仓
      如果首日暴涨30%触发止盈，次日开盘清仓
```

### D1 起

```
_sellable_shares = 前一日持仓（T日可卖）
_locked_shares   = T日新买入（T+1日才能卖）

做T机制:
  正T(先买后卖): 需要现金 + 可卖老仓（平仓时卖老仓）
  反T(先卖后买): 需要可卖老仓（先从老仓里卖）
  每轮做T消耗可卖老仓数量
  每日最多轮数 = 阶段参数 max_daily_rounds
```

### 回测验证结果（4支2026年科创板新股）

**测试标的**：688805 / 688807 / 688799 / 688797，覆盖 36-42 个交易日，首日价格 ¥48-448。

#### 场景一：首日按阶段仓位入场（D0 25%仓位，D1起做T）

| 股票 | 首日价 | 首日振幅 | 总收益 | 最大回撤 | 做T笔数 | 做T盈亏 | 做T胜率 | 每笔均值 |
|------|:-----:|:------:|:-----:|:------:|:-----:|:------:|:-----:|:------:|
| 688805 | ¥49 | 1.6% | **+18.7%** | -4.7% | 14 | +705 | 21% | +50 |
| 688799 | ¥48 | 1.1% | **+15.5%** | -9.6% | 20 | -1,368 | 7% | -68 |
| 688797 | ¥448 | 31.8% | +13.7% | 0% | 0 | 0 | — | — |
| 688807 | ¥405 | 1.5% | -8.3% | -12.4% | 0 | 0 | — | — |

#### 场景二：首日满仓入场（模拟被套 → 做T解套）

| 股票 | 总收益 | 最大回撤 | 做T笔数 | 做T盈亏 | 做T胜率 | 单笔均值 |
|------|:-----:|:------:|:-----:|:------:|:-----:|:------:|
| 688805 | **+121.6%** | -6.7% | 6 | +1,300 | 17% | +217 |
| 688807 | +36.5% | -13.1% | **7** | **+7,015** | 14% | **+1,002** |
| 688799 | +43.8% | -21.9% | 18 | +1,875 | 11% | +104 |
| 688797 | +30.4% | 0% | 0 | 0 | — | — |

### 关键发现

**1. 做T引擎有正贡献**

4支股票中，有参与做T的股票（688805/688807/688799），做T盈亏全部为正（+705 ~ +7,015）。在满仓解套场景下，做T平均贡献了持仓收益之外 **+1,300 ~ +7,015** 的额外利润。

**2. 高价股做T效率最高**

688807（¥405）仅7笔做T就获得了 +7,015 的收益，单笔均值 +1,002。原因是高价股每 tick 的绝对金额大，同样的百分比振幅对应更大的利润空间。

对宇树科技（¥150.80）的启示：属于中高价股，做T效率应介于 688807（¥405，单笔+1,002）和 688799（¥48，单笔+104）之间。

**3. 最大风险：尾盘强制平仓**

688799 场景一中，20笔做T有14笔被「强制平仓」吃掉利润。原因分析：

- 持仓后价格在VWAP附近震荡，达不到止盈目标
- 时间到14:50，系统强制平仓
- 此时往往在成本价附近，扣除手续费后小幅亏损

**已针对优化**（688836 配置）：
- 时间止损收紧：60min → 45min（更早判断，避免拖到尾盘）
- 漂移检测更敏感：6bar → 5bar
- 止盈衰减更激进：最小留存 30%

**4. 暴涨股不需要做T**

688797 首日从 ¥448 涨到 ¥585（+30.6%），触发止盈→当天清仓。后续36天没有任何做T机会——因为已经清仓了。

**这是正确行为**：首日30%+利润已经远超任何做T能提供的收益。系统在首日仍然检查风控（止盈止损），不会因为T+1锁定而错过止盈窗口——止盈会在次日开盘执行。

## 风控体系

### 底仓风控

| 机制 | 首日 | 首周 | 稳定期 | 说明 |
|------|:---:|:---:|:---:|------|
| 止盈 | 35% | 35% | 30% | 达到即次日清仓 |
| 止损 | -20% | -20% | -15% | 触发即清仓 |
| 紧急清仓 | -40% | -35% | -25% | 日内即清仓 |

### 被套分级（门槛随阶段变化）

| 级别 | 首日 | 首周 | 早期 | 稳定期 | 策略 |
|------|:---:|:---:|:---:|:---:|------|
| L0 | >-12% | >-8% | >-6% | >-5% | 正常双向做T |
| L1 | -12~-25% | -8~-15% | -6~-12% | -5~-10% | 正常做T |
| L2 | -25~-35% | -15~-25% | -12~-20% | -10~-18% | **优先反T**（只卖不买） |
| L3 | -35~-40% | -25~-35% | -20~-30% | -18~-25% | 激进减仓+反T |
| 紧急 | <-40% | <-35% | <-30% | <-25% | **立即全部清仓** |

### 日内做T风控

| 机制 | 说明 |
|------|------|
| 单轮止损 | 阶段参数 sl_pct（1.5-2.0%） |
| 日累计亏损 | 总资产的 3-6% |
| 连续亏损 | 5次连续做T亏损 → 当日停做 |
| 14:50 强制平仓 | 所有未平做T仓必须平 |
| 14:40 禁止开新仓 | 尾盘10分钟不新建仓位 |

## 交易信号引擎

### 入场信号（多维度综合判定）

```
信号来源:
  ├── VWAP偏离:  价格低于VWAP Nσ → 正T（先买后卖）
  │              价格高于VWAP Nσ → 反T（先卖后买）
  ├── 日内区间:  价格在日内低位0-25% → 正T
  │              价格在日内高位75-100% → 反T
  ├── 动量确认:  短期MA > 长期MA → 正T
  │              短期MA < 长期MA → 反T
  ├── K线形态:   前一根阴线 → 正T入场
  │              前一根阳线 → 反T入场
  └── 量价:      成交量放大确认趋势

置信度 = 多信号交集数 / 总信号数
正T仅需1个信号（更激进），反T需2个信号（更保守）
```

### 离场信号

```
退出条件:
  ├── 止盈:     浮盈达到阶段TP目标
  ├── 止损:     浮亏达到阶段SL目标
  ├── 时间止损: 持仓超45分钟后SL收紧至50%
  ├── 漂移检测: 连续5根K线向不利方向移动 → 半仓平
  ├── 尾盘保护: 14:40后微利即平（≥50%最小盈利）
  ├── 动量转弱: MA信号反转 + 微利 → 平仓
  └── 强制平仓: 14:50仍未平仓 → 按市价平
```

### 特殊机制

| 机制 | 触发条件 | 效果 |
|------|---------|------|
| 超跌反弹正T | 日内跌幅>4% + 价格在低位15%以下 | 绕过情绪抑制，强制正T |
| 反弹日检测 | 前日跌>8% + 当日开盘涨>2% | 强制正T方向 |
| 方向翻转 | 价格反向突破2.5x ATR + MACD+量确认 | 翻转做T方向，冷却15根K线 |
| 熊市隔夜 | 14:50 + 反T持仓 + 情绪<-0.2 | 反T不平仓，转为隔夜卖→次日买回 |
| 止盈衰减 | 13:00起线性衰减，14:50降至30% | 午后止盈门槛逐步降低 |

## 配置指南

### 通用配置 vs 专属配置

```yaml
# 通用配置 (ipo_config.yaml)
# 适用于大多数新股，参数偏保守

# 宇树专属配置 (ipo_688836.yaml)  
# 基于通用配置，针对高价热门股优化:
#   - VWAP σ 更宽 (首日 3.0 vs 2.5)
#   - 止盈更高 (首日 4% vs 3%)
#   - 仓位更保守 (首日 25% vs 30%)
#   - 止损更宽 (首日 2% vs 1.5%)
```

### 为新股票创建配置

1. 复制 `ipo_config.yaml` → `ipo_{code}.yaml`
2. 根据发行价/赛道热度调整 `ipo_phase.phases` 参数
3. 高价股(>¥100)：VWAP σ 和 TP 上调 20-30%
4. 冷门股：仓位下调到 15-20%
